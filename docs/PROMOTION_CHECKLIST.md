# 실매매 승격 체크리스트 — "확실한 우위"의 정의

> 2026-09-16 작성. 사용자 목표: *운용과 백테스트가 같은 환경 · 매매 동기·매수·매도 시점에 기준 · 호가·체결량·거래대금으로 RL 학습 ·
> 통계적 완전성 없는 룰베이스 지양 · 손절·익절 시점도 학습 · 확실한 우위를 세운 뒤 실매매 준비.*
>
> **이 문서의 목적은 "좋아 보인다"를 못 쓰게 만드는 것이다.** 아래 7+4 항목을 전부 통과해야 1주 실주문으로 올린다.
> 하나라도 미달이면 승격하지 않는다 — 판단이 아니라 규칙이다.

## A. 통계 게이트 (전진 데이터, 각 연구 사전등록 §6)

전진 = 정책이 고정된 **뒤에** 수집된 거래일. 판정은 연구마다 **한 번**(research/runs/<study>/FINAL 로 잠긴다).

| # | 조건 | 왜 |
|--:|---|---|
| 1 | 거래당 순수익 평균 > 0 | 비용(23bp) 차감 후에도 남아야 한다 |
| 2 | 날짜 클러스터 부트스트랩 95% CI 하한 > 0 | 하루 운으로 만든 평균을 배제 |
| 3 | 상위 1% 거래 제거 후 평균 > 0 | 한두 건의 꼬리 의존 배제 |
| 4 | 일평균 음수인 날 ≤ 1/3 | 특정 하루에 몰린 수익 배제 |
| 5 | Deflated Sharpe 확률 > 0.95 (누적 시행 N 반영) | 2,300여 회 시도 중 고른 편향 보정 |
| 6 | 무작위 진입 대조 대비 p < 0.05 | "아무 때나 사도 같다"를 배제 |
| 7 | 전진 거래일 ≥ 10 · 거래 ≥ 30 | 표본 부족으로 판정 자체를 금지 |

## C. 승격 절차 (A·B 전부 통과 시)

1. 그날 `docs/TRADING_CRITERIA.md` 에 **매매 기준 확정판**을 적는다(무엇을·왜·언제 사고 판다).
2. 1주 실주문으로 시작한다. 첫 5거래일은 **관찰 기간**.
3. 롤백 규칙(사전 고정): 관찰 5일 중 **누적 실현 손실이 전진 기간 일평균의 3배를 넘으면 즉시 dry-run 복귀**.
4. 규모 확대는 별도 연구(체결 모형이 1주 가정 위에 있다).

## E. 룰베이스 처리 원칙

86번 호랑이 규칙은 **기준선(baseline)** 으로만 유지한다. A 게이트를 통과하더라도, 통계적 완전성(사전등록·전진·대조)이
RL 정책과 같은 수준으로 충족될 때만 승격 후보가 된다. 사람이 문턱을 손으로 고른 규칙을 먼저 올리지 않는다.
