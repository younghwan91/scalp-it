# 사전등록 — 엑싯 규칙 4종 비교

**작성 시각:** 2026-08-17, 측정 **이전**
**목적:** 엑싯 규칙은 탐색 공간이 무한하다. 무엇을 왜 재는지, 어떤 결과든 그대로 보고한다는 것을 먼저 못 박는다.

## 왜 재는가

현재 규칙은 D+1 시가 진입 → D+40 종가 청산의 고정 보유다. 분포를 보면
평균 +7.14% 인데 중앙값 +2.33%, 승률 53.9%, 손익비 1.90:1 이다.
**평균은 오른쪽 꼬리가 만든다.**

두 가지 실무적 요구가 있다:

1. **자본 효율** — D+40 고정이면 하루 2건 선택 시 동시 보유 80종목이다.
   개인 계좌에서 불가능하다. 안 되는 포지션을 일찍 비우면 같은 자본으로
   더 많은 기회를 잡는다.
2. **분포 개선** — 왼쪽 꼬리(p5 = −27.4%, 최소 −64.8%)를 자르면 중앙값과
   손익비가 개선될 수 있다.

## 반대 증거를 먼저 적어둔다

**프랍 스윙 탐색(2026-07-18)에서 PEAD-집중이 죽은 직접 원인이 손절이었다.**
10% 손절 + 10일 캡이 "승자를 자르고 노이즈를 확정"했다. 스펙 §2 가
"드리프트를 자르지 않는다"를 강제 조건으로 박은 이유다.

그리고 보유일별 곡선은 **60일까지 피크가 없다**. 평균·중앙값·승률·손익비가
전부 우상향이다 (D+10 손익비 1.52 → D+60 2.19). 짧게 끊을 근거가 데이터에 없다.

**따라서 이 실험의 사전 기대는 "엑싯 규칙이 도움이 안 된다" 이다.**
도움이 된다는 결과가 나오면 그때 더 의심해야 한다.

## 비교할 규칙 4종 (전부 D+1 시가 진입)

| 이름 | 규칙 |
|---|---|
| `H40` | D+40 종가 청산. **기준선** |
| `CULL10` | D+10 종가에 진입가 대비 수익 ≤ 0 이면 그날 청산. 아니면 D+40 |
| `STOP15` | 종가가 진입가 대비 −15% 이하로 마감하면 그날 청산. 아니면 D+40 |
| `BOTH` | `CULL10` + `STOP15` 동시 적용 |

**파라미터 근거 (성과를 보고 정한 것이 아니다):**

- **D+10 체크포인트** — 보유일별 곡선에서 중앙값이 0 을 넘는 지점이 D+15 다.
  D+10 은 그 직전으로, "아직 시작도 안 했다"를 판정할 수 있는 가장 이른 시점이다.
- **0% 임계** — 손익의 자연 경계다. 다른 값을 시도하지 않는다.
- **−15% 손절** — 관측된 평균 손실(−12.63%)보다 조금 넓게 잡은 반올림 값이다.
  평균 손실 안쪽에 두면 정상 변동을 자른다. **−10%·−20% 는 시도하지 않는다.**

각 값은 **하나씩만** 시도한다. 그리드를 돌려 최적을 고르지 않는다.

## 규칙은 실제 가격으로, 평가는 초과수익으로

손절과 컬은 **원 수익률(진입가 대비)** 로 판정한다 — 실전에서 손절은 주가에 걸지
시장 대비 초과수익에 걸지 않는다. 반면 성과 평가는 **초과수익**으로 한다 —
이 프로젝트의 일관된 지표다.

## 보고할 것 — 평균만 보지 않는다

규칙마다 전부 적는다:

- n, 평균, **중앙값**, 승률, **손익비**(평균이익/평균손실)
- 분위 p5 / p25 / p75 / p95, 최소, 최대
- **평균 보유일** — 자본이 얼마나 묶이는가
- **자본시간당 수익** = 평균 초과수익 / 평균 보유일 × 20 (20거래일 환산)
- 동시 보유 추정 = 하루 선택 수 × 평균 보유일

**자본시간당 수익이 핵심 비교축이다.** 총수익이 낮아도 자본이 빨리 풀리면
같은 자본으로 더 돌릴 수 있다.

## 결과를 어떻게 다룰 것인가

- **네 규칙 전부 보고한다.** 좋은 것만 고르지 않는다.
- 기준선(`H40`)이 이기면 그대로 두고 끝낸다. **엑싯 규칙 탐색을 더 하지 않는다.**
- 어떤 규칙이 이기더라도, 그것은 **같은 데이터에서 4개를 본 결과**다.
  전진 검증으로만 확정한다. 백테스트 결과로 운영 규칙을 바꾸지 않는다.
- 폴드별로도 쪼개 본다. 4폴드 중 일부에서만 이기면 채택하지 않는다.
