# ②층 공시 판정 — 이벤트 정의는 옳았고, 공시 피처는 값을 못 했다

**날짜:** 2026-08-17
**재현:** `scalp-dart-layers --dart-db data/dart_2024.db --start 2024-01-01 --end 2026-08-14 --top-n 2`
**결과:** `results/dart_layers_2024.json`
**표본:** 이벤트 48,928 · 종목 1,734 · 2024-01-30 ~ 2026-06-18 · 공시 335,179건

**피처를 10개 더했는데 모든 축에서 조금씩 나빠졌다.** 평균도, 하방도, 최종창도.
전형적인 무의미 피처 추가의 모습이다 — 새 정보 없이 자유도만 늘었다.

**이것이 층 구조를 만든 이유다.** ②가 ①을 못 이기면 ③(LLM)·④(뉴스)에 갈 근거가
없다는 것을 무료로, 지출 전에 알게 됐다.

## 그런데 더 큰 것이 나왔다 — 이벤트 정의가 옳았다

같은 수급 피처, 같은 라벨, 같은 게이트인데 **이벤트 정의만 다르다:**

| 이벤트 정의 | 이벤트 수 | strategy | net | 풀/일 | 선별비율 |
|---|---|---|---|---|---|
| 거래대금 급증 (rev1) | 14,122 | +3.00% | +2.54% | 24.4 | 0.082 |
| **공시 접수 (rev2)** | **48,928** | **+7.61%** | **+7.15%** | 84.8 | **0.024** |

**2.5배 좋아졌고, 표본은 3.5배 늘었고, 선별도는 3배 엄격해졌다.**

스펙 rev2 의 네 가지 근거가 데이터로 확인됐다 — 특히 "급증 종목의 재료를 찾는 것은
이미 오른 걸 보고 이유를 붙이는 역인과"라는 지적이. 재료 발생을 시작점으로 잡으니
같은 신호가 훨씬 깨끗하게 잡힌다.

부수 사실: 공시 이벤트의 랜덤 널은 **+1.70%** 로 양수다. 거래대금 급증 이벤트의
널이 −2.95% 였던 것과 대조된다. **공시가 난 종목은 평균적으로 나쁘지 않고,
거래대금이 급증한 종목은 평균적으로 나쁘다.** 후자에서 이기는 것은 "덜 잃기"였고
전자에서 이기는 것은 "더 벌기"다.

## 정리하면 신호는 이렇게 생겼다

```
공시가 난 종목 중                          ← 이벤트 정의 (rev2). 크게 기여
  외국인·기관이 순매수한 것을 사라           ← 신호의 본체
공시의 종류·건수·신선도는                   ← 추가 정보 없음
  D+20~40 초과수익을 설명하지 못한다
```

## 남은 결함 — 폴드 0

두 층 모두 **폴드 0(2024년 초반)에서 널을 못 이긴다** (백분위 48.5 / 47.0).
①층을 거래대금 급증 이벤트로 쟀을 때도 폴드 0 이 가장 약했다(pct 96.0, gap +2.33%p).

폴드 0 은 유니버스가 막 확장된 직후 구간이다. `supply_demand` 가 2024-01 부터
2,700종목으로 늘었으니, 폴드 0 의 학습 데이터는 거의 없고(첫 폴드) 검증 대상은
새 유니버스다. **첫 폴드는 구조적으로 불리하다** — 학습 표본이 가장 적다.

이것이 "종합 FAIL" 의 유일한 원인이다. 다른 세 조건은 전부 통과했다.
다만 **기준을 바꾸지 않는다.** 4개 중 3개가 통과했다고 승격하지 않는다.

## 이것이 로드맵에 미치는 영향

앞서 세운 순서는 `① → ② → ③(LLM) → ④(뉴스)` 이고 각 층은 앞 층을 이겨야 승격이었다.

**②가 졌다. 따라서 ③·④는 보류한다.**

- **③ LLM (공시 원문)** — 공시의 *유형·건수*가 정보를 안 줬는데 *본문*이 줄 것이라는
  근거가 약하다. 계약금액·매출액 대비 같은 구조화 필드는 여전히 시도해 볼 값이
  있지만, 그건 ②층 피처를 정교화하는 것이지 새 층이 아니다. **우선순위를 내린다.**
- **④ 뉴스** — 유료(뉴스토어) 또는 수동 36회+. **재료 내용 축이 두 번 값을 못 한
  상태에서 지출할 근거가 없다.** 뉴스토어 견적은 받아두시되 결제는 하지 마시라.

**대신 ①층이 실재한다.** 공시 이벤트 + 스마트머니로 net +7.15%, 최종창 +18.30%,
단조성 0.988. 자원을 여기에 쓰는 것이 맞다:

1. **전진 검증 시작** — 폴드 0 문제와 "단일 레짐 2년 4개월" 의심은 미래 데이터로만 풀린다
2. **포지션 예산 시뮬레이션** — 지금 수치는 시그널 지표이지 포트폴리오가 아니다
3. **`supply_demand` 2024 이전 백필** — 되면 전 기간 재판정이 가능해지고 폴드 0
   문제도 완화된다 (학습 표본이 앞으로 늘어난다). quant-airflow 소관
