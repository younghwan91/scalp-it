# 만쥬 대조표 — 우리 시스템이 만쥬와 어디까지 같은가

만쥬가 우리 백테스트 결과를 보고 준 답변(2026-08-26)과 문서 44 를 항목별로 대조한
것이다. **목표는 방법의 차이를 0 으로 만드는 것**이고, 남은 차이는 아래 "아직 다른
것"에 전부 적었다 — 숨기면 내일 결과를 잘못 읽는다.

배선 확인은 cron 스크립트(`scripts/pair_detect_daily.sh`)의 플래그를 **그대로
파싱해** 설정 객체까지 도달하는지 보는 방식으로 했다. 플래그가 있는데 안 닿는
사고가 실제로 있었다(호가 두께 필터가 `on_quote` 에 10단계가 안 들어와 무동작).

## 같아진 것

| 만쥬가 말한 것 | 우리 구현 | 값 |
|---|---|---|
| "상한가 호가 **3개 남겨둔** 3~5초 사이에 매수" | `limitup_near_ticks` | `--limitup-near-ticks 3` |
| "현재가 기준 **위 2~3호가** 지정가 원클릭" | `entry_ticks_up` | `--entry-ticks-up 2` |
| "5천만 원 이상 (비공개 회신 — 공개본에서 뺐다) | `min_big_trades` | `--big-trades 2` |
| 2등주 서열 = 호가두께 → 틱 체결강도 → 가벼운 소형주 | `follower_priority="manju"` | `--follower-priority manju` |
| "1회 주문을 1~2호가 안에서 받아줄 잔량"(두께) | `roundtrip_bp` 필터 | `--max-roundtrip-bp 20` |
| (비공개 회신 — 공개본에서 뺐다) 전량" | `position_notional`, 분할매수 없음 | `--position-notional 10000000` |

## 의도적으로 다르게 둔 것 — **하나뿐이다**

**시황 게이트를 8조 → 5조로 낮췄다**(2026-08-27, 사용자 결정). 만쥬 원문은
"코스닥 7~8조 이하면 신호가 떠도 진입하지 않는다"이고 우리도 8조로 뒀었다.

    코스닥 거래대금  2026-05 중앙 15.25조 → 06 9.15 → 07 6.02 → 08 6.14
    최근 20거래일 중 8조 초과 **1일** · 5조 초과 **16일**

그대로 두면 실제 체결·슬리피지·호가 데이터를 몇 주째 한 건도 못 얻는다. 1주
주문이라 손실 한도가 작은 대신 실전 데이터를 얻는 쪽을 택했다.

**이 구간의 성적은 "만쥬가 쉬라고 한 국면"의 것이므로 만쥬 규칙 검증에 쓰면 안 된다.**
5조 미만인 날은 종전대로 그림자만 쌓인다.

## 실주문이 나간다 (2026-08-27~)

`--confirm-real` 을 켰다. 안전장치는 그대로다:

    주문 수량   1주 (하드캡 10주 — 설정으로도 못 넘는다)
    가격밴드    참조가 ±3% 밖 지정가 거부
    화이트리스트 그날 유니버스(44종목) · 보유종목 차단
    횟수        종목당 5회 · 일일 20회
    킬스위치    연속손절 3회 → 당일 종료
    최대 노출   유니버스 최고가 432,500원 = 주문 1건 43만원

되돌리려면 `scripts/pair_detect_daily.sh` 실행줄에서 `--confirm-real` 을 지운다 —
그 즉시 dry-run 이다.

## 아직 다른 것 — 이유와 함께

**1. 진입 반응 속도.** 만쥬는 3~5초 창에서 산다. 우리 폴링은 1.5초이고 방아쇠는
호가 기준이라 원리는 같지만, 만쥬가 보는 "호가 3개 남은 순간"의 미시 흐름(체결 틱의
가속, 잔량이 깎이는 모양)을 사람만큼 못 읽는다. 이건 데이터가 아니라 판단의 차이다.

**2. 테마 정의**(신선도 필터 포함). 만쥬의 "피로도 높은 테마는 대장이 상을 가도
2등주가 안 따라온다"는 옳지만 우리 구현(`--stale-sector-limitups`)은 27종 산업분류의
**원시 상한가 건수**를 세서 테마 피로도가 아니라 **섹터 크기**를 쟀다. 최근 25일 실측:

    전기/전자 31건/387종목 = 8.0   IT서비스 19/254 = 7.5
    화학       12/229      = 5.2   기계/장비 10/216 = 4.6

크기로 나누면 전기/전자는 평균인데, 원시 건수 문턱 3 은 큰 섹터를 무조건 배제한다.
2026-08-27 유일한 후보(0155E0→222222)가 "전기/전자 14회 > 3회"로 잘렸다 — 정확히
거꾸로다. **꺼뒀다.** 만쥬는 아침에 손으로 만든 관심종목 (비공개 회신 — 공개본에서 뺐다)
쓴다. 우리는 27종 표준 산업분류 + 재료 공시 + LLM 채점으로 유니버스를 만든다.
만쥬가 "27종으론 실전 테마를 절대 못 잡는다"고 한 그 자리다. 잔차 동조·동반급등
이력·키움 테마를 1년치로 겨루게 해봤지만 셋 다 27종을 못 이겼다(무작위 대조군과도
차이가 없었다) — **테마 정의를 데이터로 대체하는 길은 막혔고, 사람이 아침에 만드는
목록이 답이라는 게 만쥬 말이다.**

**3. 뉴스·찌라시 진위 판별.** 만쥬가 "절대 기계화 불가"로 명시한 항목이다. 우리는
DART 공시만 쓴다(정책상 뉴스 크롤러를 안 짠다). 재탕 뻥카를 못 거른다.

**4. (비공개 회신 — 공개본에서 뺐다) 만쥬가 "직관"이라고 한 두 번째 불가 항목.
`--dump-krw`(1억 매도 틱)로 결과만 잡을 뿐, 유인 후 던지는 패턴 자체는 못 본다.

**5. 프로그램 매도 저항 장세 회피.** 만쥬는 "외인/기관이 (비공개 회신 — 공개본에서 뺐다) 했다. 우리는 **대장 종목**의 매도 폭탄만 본다. 시장 전체
프로그램 수급은 아직 안 본다.

**6. 실주문 수량.** `--qty 1`(어댑터 하드캡 10)은 실주문 안전캡이다. `--confirm-real`
이 없어 실주문은 0건이고 가상 회계는 명목 1천만원으로 돈다. 실발주로 전환하려면
이 두 개를 같이 손봐야 하고, 그건 사람이 결정할 일이다.

## 내일 무슨 일이 일어나는가

cron `55 8 * * 1-5` 로 뜬다. 그런데 **만쥬 기준 내일은 쉬는 날**이다 — 코스닥 전일
거래대금 4.44조로 `--halt-below-jo 8` 에 걸려 신규 진입이 막힌다. 만쥬가 "7~8조
이하면 신호가 떠도 안 산다"고 한 그대로다.

진입은 막혀도 **신호는 그림자로 굴러간다**(`--shadow-when-blocked`). 만쥬 규칙대로
안 사는 건 그대로고 — 실현손익·승패·연속손절·킬스위치·주문 어디에도 안 닿는다 —
대신 "샀으면 어땠나"가 남는다.

이걸 켠 이유는 시장 상태 때문이다:

    코스닥 거래대금(조)   1년 중앙 10.10 · 8조 넘는 날 68%(178일)
    2026-05 중앙 15.25 → 06 중앙 9.15 → 07 중앙 6.02 → 08 중앙 6.14
    최근 20거래일 중 8조를 넘은 날: **1일**(08-18)

만쥬 규칙은 정상 작동 중이고 1년 기준으론 68% 날을 거래했을 텐데, 하필 지금이 그
32% 구간이다. 두 달째 표본이 0 이면 만쥬 규칙이 맞는지조차 확인할 길이 없다.
그림자는 그 공백을 메우되 매매 판단은 만쥬 그대로 둔다.

거래대금이 8조를 넘는 날이 오면 그날부터 그림자가 아니라 실제 가상매매가 돈다.
