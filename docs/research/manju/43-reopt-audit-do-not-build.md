# 재최적화 프로세스 감사 — 지금은 만들지 마라 (2026-08-25)

> 사용자가 '재최적화 프로세스에 허점 없는지 검증' 지시. 감사(reopt-audit) + 프로토타입 실증(reopt-builder) 둘 다 **'지금 재최적화는 무의미·유해'** 로 일치.

## 실증된 실패 (프로토타입을 실제 DB로 돌림)
- **train-best 가 holdout 에서 부호 뒤집힘**(through·touch 둘 다). 2일뿐이라 train=1일·holdout=1일, OOS 아님. 셀당 n 한 자릿수 → 사후선택 착시.
- **비용 반영 시 net ≈ −0.5%**. 프로덕션 cost_rate=0.0 이라 로그 손익이 세전·스프레드0. 실측 스프레드(002990 0.13/094480 0.22/294570 0.28/033340 0.36%) 빼면 마진 소멸.
- **버그가 엣지로 위장**: 손절 부호 실수로 손절선이 진입가 위→매 체결 발동→가짜 'SL−0.7% 승률100%' 셀. n작으면 버그≈엣지. **검증 안 된 재최적화 = 버그를 엣지로 착각하는 기계.**

## 낙관 편향(기준 로직 상속)
- 미완결 포지션 MFE(최고가) 청산, 손절 무슬리피지, 킬스위치가 그리드 평가 중 작동해 지는 셀 조기절단.

## 선결 조건 (충족 전 재최적화·실발주 금지)
1. 수십 거래일 축적(현 2일) 2. 비용 실측(세금+종목별 스프레드) 3. 킬스위치 라이브만·그리드 OFF 4. 진짜 holdout(train만 argmax) 5. 미완결 마지막가 청산+손절 슬리피지 6. 멱등(틱재생, 로그append 아님)

**그때까지: 현행 유지** — dry-run 감지기(pair_detect_daily.sh) + 일일집계(pair_daily_summary.py) 로 손실0 관찰만.
