# 사전등록 (59번) — 상따 당일청산형 재검증

> 2026-09-06 작성, **측정 전 커밋**. `54-implementation-backlog.md` §2-10 정정 과정에서
> 나온 별개 가설이다. 표본·피처·판정선을 여기서 고정한다.

## 0. 왜 이걸 재나

`06-closebet-preregistration.md` 4~5차는 "상따"를 **트리거 분 종가 매수 → 익일 시가
매도(오버나이트)**로 정의해 3회(06·[21](21-dart-catalyst-preregistration.md)·
[15](15-newlisting-preregistration.md)) 측정·기각했다("재시도 없음", AUC 0.523,
net34 −2.09%).

그런데 만쥬 44 §4-2("대장주 매매(상따·긴 시세 분출)")·§4-3("오버나이트 절대 금지")과
현재 짝꿍 시스템(`--duration ...-15:20`)을 같이 보면, 만쥬가 말하는 상따는 **당일
청산**을 전제한다고 읽는 게 더 자연스럽다. 06번이 기각한 net34 −2.09%가 "대장 신호
자체에 정보가 없다"인지 "오버나이트 갭이 정보를 깎아먹었다"인지는 그 결과 하나로
구분할 수 없다 — 이걸 가르는 게 이번 측정의 유일한 목적이다.

**실행 가능성 제약을 먼저 밝힌다.** 트리거 이벤트의 28.3%는 그날 상한가로 마감해
잠긴다(06번 5차 확정 수치). **잠긴 종목은 당일에 팔 수 없다** — 매수 잔량만 쌓이고
매도 물량이 없다(06번 "철회 확정" 절, 15:30 단일가 체결 비상한가 대비 1/40).
따라서 "당일청산형"은 "무조건 당일 매도"가 아니라 **"팔 수 있으면 당일 매도, 못
팔면(잠기면) 어쩔 수 없이 익일 시가까지 보유"** 로 정의해야 정직하다. 후자 서브셋은
기존 기각된 오버나이트 결과와 정의상 동일하다.

## 1. 표본 — 측정 전 고정

06번 5차 확정과 **완전히 동일한 이벤트 정의**를 그대로 재사용한다(새로 고르지 않는다):

```
유니버스   당일 거래대금 >= 500억 (백만원 단위 50,000)
트리거     분봉 고가가 전일종가 x 1.25 를 처음 넘는 그 분
진입       그 분의 종가 (사전등록대로)
기간       2025-08-01 ~ 2026-08-21, 분봉 보유 전 종목 (06번 확정과 동일: 1,809건/722종목/253거래일 기대)
```

`scripts/verify_sangtta.py`의 `build_events()`를 **그대로, 수정 없이** 재사용한다.
그 스크립트는 이미 3회 판정을 낸 닫힌 코드라 손대지 않는다 — 새 스크립트에서
import 만 한다.

## 2. 피처 — 이번엔 분류 모델 없음

06번 5차의 1단계(8피처 GBM으로 상한가 마감 예측, AUC 0.523)는 **청산 방식과 무관한
결과라 재실행하지 않는다.** 이미 기준(0.60) 미달로 닫혀 있다. 이번 측정은 순수
기술 통계(청산가만 바꾼 수익률 비교)이며 모델 적합·피처 선택을 하지 않는다.

새로 추가하는 것은 청산가 계산에 필요한 값 하나뿐이다:

- `close_1519` — 그날 15:20 이전 마지막 분봉 종가 (동시호가 직전 마지막 체결가)
- `locked_1519` — `close_1519 >= prev_close * 1.295` (기존 `LIMIT_AT_ENTRY` 임계 재사용,
  진입 시점 잠김 판정과 같은 기준). 상한가 정확한 호가단위 계산은 안 하고 06번이
  이미 쓰던 근사를 그대로 쓴다.

## 3. 모델 — 하나만, 청산 규칙 하나만 비교

```
exit_sameday = close_1519          (locked_1519 == False 인 경우)
             = n_open (익일 시가)   (locked_1519 == True 인 경우 — 강제 보유)

ret_sameday = (exit_sameday - entry) / entry
```

**다른 청산 시각·다른 잠김 임계를 시도하지 않는다.** 15:00 컷, 14:30 컷 등 변형 금지.

비교 대상(참고용, 판정에는 안 씀): 06번 확정 수치(전량 오버나이트, net34 −2.09%).

## 4. 분할 — 시간 순

06번 5차와 동일하게 표본이 1년(2025-08~2026-08)뿐이라 무작위 분할 대신 **날짜순
3폴드**를 쓴다. 연도별 비교는 하지 않는다(11년 결과와 같은 표에 놓지 않는다 —
06번 6차 이후 관행).

## 5. 판정선 — 측정 전 고정

**채택(추가 조사 가치 있음) 조건, 06번 5개 조건을 이 가설에 맞게 대응시킨다.
AND 로 전부 만족해야 한다:**

1. 블렌드(잠김 강제보유 포함) 표본 전체 net34 > 0
2. 시간순 3폴드 중 음수 폴드 ≤ 1
3. 상위 1% 제거 후에도 블렌드 net34 > 0
4. **당일 매도분만(잠기지 않은 서브셋) net34 > 0** — 이게 진짜 신규 정보다.
   잠긴 서브셋은 정의상 기존 오버나이트 결과와 같으므로 판정에 넣지 않는다
5. 블렌드 승률 > 50%

**하나라도 못 넘으면 기록하고 접는다. 파라미터를 바꿔 재시도하지 않는다** — 06번과
같은 원칙.

## 6. 통과하면 무엇을 하나

06번 관행 그대로: **실전 투입 아님.** 통과해도 그림자 배선 → 전진 기록 →
별도 승인 절차를 거친다. 이 문서는 그 이전 단계(측정)만 다룬다.

## 7. 산출물

## 해석 — 가설이 틀렸다, 반대 방향으로

§0 의 질문은 "오버나이트 갭이 정보를 깎아먹었나"였다. 답은 **아니다** — 정반대다.

- **잠긴 30%가 수익의 전부다**(net34 +7.99%, 승률 88.2%). 이건 06번이 "상한가 마감
  1,365건 +7.51%"로 이미 확인한 것과 같은 구조다.
- **되돌린 70%(당일 매도분)는 오버나이트 청산보다 훨씬 나쁘다**(net34 −6.85% vs
  06번 확정 전량 −2.09%). +25% 를 찍고 되돌리는 종목은 **그날 안에 더 깊이
  떨어진다** — 15:19 까지 하락이 계속되는 경우가 많아 승률이 14.3% 까지 떨어진다.
  오버나이트로 넘기면 다음날 시가에 어느 정도 반등/안정화될 여지가 있었는데,
  당일 매도는 그 반등 기회를 원천 차단하고 **하락이 가장 깊은 시점(장중)에 파는
  꼴**이 된다.

**결론:** "오버나이트형과 당일청산형은 별개 가설"이라는 §0 의 전제는 맞았지만,
당일청산이 **더 나은 게 아니라 더 나쁜** 별개 가설이었다. 상따의 근본 문제(+25%
도달 시점에 잠길지 되돌릴지 분봉 정보로 못 가른다, AUC 0.523)는 청산 방식과
무관하게 그대로다 — 청산을 당일로 당기면 그 미분류 리스크를 더 나쁜 타이밍에
확정시킬 뿐이다.

**재시도 없음.** 06/21/15번과 같은 원칙 — 상따는 청산 방식을 어떻게 바꿔도
분봉 수준에서는 살아나지 않는다. 남은 경로는 06번이 이미 적어둔 대로 **호가·틱
데이터**(잠김 여부를 트리거 시점에 미리 가르는 것)뿐이다.
