### 원주가 / 수정주가 환산

돌파선은 `daily_bars_adjusted`(수정주가)로 계산하고 분봉은 원주가다.
`돌파선_raw = 돌파선_adj × raw_close(D) / adj_close(D)` — 비율은 D 당일의 수정계수이며 가격 정보가
아니다(권리락은 사전에 공지된다). 권리락 당일도 이 식으로 맞는다.

## 판정 절차

### 0단계 — 보고만 (판정 아님)

n · 월별 건수 · 상한가 잠김으로 제외된 건수 · `ret_at_trigger ≥ 20%` 건수 ·
**당일 상한가 마감 건수와 그 기여** (분리 보고, 아카이브 실패 6 의 교훈).

### 1단계 — 무조건 진입 (주 규칙 `손절2`)

06번과 같은 항목을 보고한다: n, 하루 건수, 평균·중앙값, 승률, 손익비, p5/p25/p75/p95, 비용 4단계,
상위 1% 제거 후 평균. 여기에 더해:
- **월별 폴드** — 1년이라 연도 분할이 불가능하다. 달력월 폴드, **이벤트 ≥ 100건인 달만 센다**
  (아래 측정에서 13개월 중 11개월)
- **독립 이벤트**(직전 5거래일 내 같은 종목 이벤트 없음)만의 결과 — 연속 돌파 군집 제거
- 분봉 보유 종목만 / 보충 수집 후 전체 — 둘 다

**채택(전진 기록 착수) 조건, 전부 만족:**

1. 34bp 차감 후 평균 > 0
2. **월별 폴드 중 음수 월 ≤ 3** (11개월 기준; 06번의 "음수 해 ≤ 2/11"에 대응)
3. 상위 1% 제거 후 34bp 평균 > 0
4. 독립 이벤트만으로도 34bp 평균 > 0
5. 55bp 차감 후 평균 > 0

06번의 "승률 > 50%"는 넣지 않는다 — 손절 규칙은 구조적으로 승률을 낮추고 손익비를 높이므로
무관리 종가베팅용 조건이었다. 대신 5번(보수 비용)을 둔다. **이 교체가 맞는지는 사용자 판단.**

**예측 가능성 (같은 단계에서 보고):** 8개 피처로 라벨 **"+2% 가 −2% 보다 먼저 닿음(당일)"** 을
예측하는 얕은 GBM (max_depth=2, n_estimators=100), **시간순 3폴드** (5차와 동일). AUC 를 보고한다.

- 1단계 채택 조건 통과 → 채택. 2단계 생략.
- 실패 → **AUC ≥ 0.60 이면 2단계**, 아니면 돌파를 접고 기록한다.

### 2단계 — 선별 진입

폴드 **안에서** 예측 점수 상위 1/3 만 진입 (전역 풀링 금지 — 아카이브 실패 4). 주 규칙 수익에
1단계와 같은 5개 조건. 참고로 **하루 상위 2건**(예측 점수 순, 만쥬의 실제 빈도) 결과를 함께 보고하되
판정은 상위 1/3 로 한다.

비교 규칙 `스승`·`무관리`는 1단계에서 각 1회만 측정·보고한다.

## 미리 밝히는 한계

- **상한가.** 진입 분이 잠긴 건은 제외한다(체결 불가). 당일 상한가 마감은 **매도는 가능**하므로
  제외하지 않되 기여를 분리 보고한다. 단, +25% 부근 VI·상한가 직행 구간의 진입 체결 실현성은
  의심스럽다 → 55bp 를 조건에 넣었다. **상한가 마감 건을 제외해도 > 0 을 조건으로 걸지 여부는
  사용자 판단** — 걸면 돌파 매매의 정당한 오른쪽 꼬리를 자르고, 안 걸면 상따에서 본 "되돌림 70%"
  구조를 놓칠 수 있다.
- **슬리피지.** 돌파 분은 체결이 몰린다. 분 종가 체결, 손절가 체결 가정 모두 **낙관 방향**.
- **1년 · 한 레짐.** 이벤트의 **64%가 2026-01~05** 에 몰려 있다(월별 표). 월별 폴드를 써도
  강세장 하나를 보는 것이다. 2026-07 은 41건뿐이다.
- **생존편향.** `minute_bars` 725종목은 **2026-08 기준** 20일 평균 거래대금 상위다 — 1년간 오른
  종목이 과대 포함된다. 이벤트 종목 825개 중 분봉 보유는 483개. 나머지 342개는 아래 JSON 으로
  보충 수집한다. **보충 전 부분표본 결과는 판정에 쓰지 않는다.**
- **원주가/수정주가.** 위 환산식으로 처리. 수정계수 오차로 돌파선이 호가단위 안에서 흔들릴 수
  있다 — 동률(=)은 돌파가 아니다(strict >).
- **신규 상장주 제외** (250일 이력 필요). 만쥬의 신규주 매매는 별도 기법이다.
- **연속 돌파 군집.** 종목당 이벤트 중앙값 5건, 최대 45건. 같은 추세의 날들이 관측을 부풀린다
  → 독립 이벤트 조건 4.
- **호가·순간체결량·프로그램 수급 없음.** 실패해도 "만쥬 방식이 틀렸다"가 아니라 "분봉으로는
  부족하다"일 수 있다.
- **3:3:4 분할·불타기 미재현.** 우리 진입은 만쥬의 3차 시점이다 → 불리 방향.
