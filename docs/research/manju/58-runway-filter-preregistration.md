## 0. 왜 이걸 재나

타 트레이더 B B-1 실행 지시서(50번): "Clear upward runway: Target resistance (e.g.,
2nd VI or Upper Limit) must be open." — 진입 순간 위쪽에 저항(2차 VI·라운드
피겨·전고점)이 바로 있으면 더 못 뻗고 막힌다는 것. 54번은 이 필터를 "계산은
즉시 가능"으로 분류했다.

**이번엔 2차 VI 는 뺀다.** 실시간 VI 이벤트 테이블(`vi_events`)이 스키마만
있고 데이터가 0건이다(54번 §3-1, 앱키 등록 한도로 아직 못 붙임). 시뮬레이션도
가능하지만(정적 VI 는 기준가 대비 ±10%로 계산 가능) 이번 라운드는 **가격
데이터만으로 바로 되는 두 피처(라운드피겨·전고점)만** 잰다. VI 는 §6 다음
과제로 남긴다.

accel(56·57번)과 같은 방법론(대장 자신의 forward 수익 대리 측정, 분위·부트
CI·비용후·국면 층화)을 그대로 따른다 — 이번이 두 번째 적용이라 그 틀이
검증됐다고 보고 반복한다.

## 1. 표본 — accel(57번)과 동일

- 트리거 = 서지 조건(4분 +2%, `accel_sanity_minute.py`와 동일 정의) — 같은
  트리거 위에서 "그때 위가 열려 있었나"만 다르게 잰다
- 국면별 층화 20일씩(활황·중간·침체·극침체), 세션 09:00~15:20
- 데이터: `minute_bars`(가격) + `daily_bars`(전고점 계산용, 트리거일 **이전
  거래일까지만** — 당일 고가를 쓰면 미래참조다)

## 2. 신호 — 두 피처 (측정 전 고정, 사후 재정의 금지)

### (a) 라운드피겨 갭

    step(p) =  100      p <  1,000
               500      1,000 <= p < 5,000
               1,000    5,000 <= p < 10,000
               5,000    10,000 <= p < 50,000
               10,000   50,000 <= p < 100,000
               50,000   p >= 100,000

    다음 라운드 레벨 = ceil(p / step) * step  (p 가 이미 배수면 + step 더함)
    round_gap_pct = (다음 라운드 레벨 - p) / p

값이 작을수록(가까울수록) 저항이 임박 — **런웨이 없음**. 클수록 열려 있음.
KRX 정식 규정이 아니라 **우리가 고정하는 근사**다(호가단위와 다른 개념).

### (b) 전고점 갭

    prior_high = max(daily_bars.high, 최근 60거래일, 트리거일 이전 영업일까지)
    prior_high_gap_pct = (prior_high - p) / p

음수면 **이미 전고점을 뚫은 상태**(위가 열려 있음 — 만쥬 원문 취지와 정합).
60거래일은 "52주 신고가"의 근사다(1년 전부는 유니버스가 데이터 범위 안 들어와
있는 종목이 있어 60일로 낮췄다 — 최근 3개월 고점 돌파도 상단 저항 신호로 보는
쪽이 표본을 더 준다).

## 3. 라벨·시험·판정선 — 57번과 완전히 동일한 절차

지평 N∈{300,600,1200}초, close·MFE, 부트 95%CI, 비용 40/50/60bp, 각 피처를
5분위로 나눠 단조성(Q5>Q1, gap 클수록 forward 좋아야 가설과 일치), 최소표본
100. 두 피처 각각 독립적으로 판정하고, 국면별 + 전체 풀링 모두 낸다.

## 4. 통과해도 하는 일

# 결과 (2026-09-06 측정, 국면별 20일씩 총 80일 · 트리거 91,527건)

## 판정: **두 피처 다 미확인**(하나는 무신호, 하나는 반대 방향)

### (a) 라운드피겨 갭 — **무신호**

전체 풀링·4개 국면 전부에서 5분위 close 평균이 −0.36~−0.50%대에 평평하게
뭉쳐 있고(활황 Q1 −0.239 vs Q5 −0.191, 거의 차이 없음), 중앙값 문턱 pass/fail
차이의 부트 95%CI 가 **모든 셀에서 0을 낀다**(방향 없음, 유의한 반대도
아님). 라운드 레벨까지 거리는 이 정의로는 forward 수익과 관계가 없다.

### (b) 전고점 갭(60거래일) — **방향이 가설과 반대**

    활황 N=600s: pass(gap≥24.6%, 아직 멀리 아래) −0.294% vs fail(gap<24.6%,
                 최근 이미 근접·돌파) −0.124%  (차 −0.169%p, CI[−0.234,−0.103])
    전체 풀링 12셀 중 8셀이 유의 음수(CI 상한도 0 미만), 나머지도 방향은 전부 음수

**"전고점까지 멀수록(런웨이가 넓을수록) forward 가 좋다"는 가설과 정반대다.**
오히려 **이미 최근 고점 근처거나 돌파한 채로 서지하는 쪽이 forward 가 낫다**
— "위가 비어 있어서 좋다"가 아니라 "이미 저항을 뚫고 있다는 것 자체가
질 좋은 움직임의 증거"로 읽힌다. 이건 이 사전등록이 검증하려던 가설과는
다른 가설이라 여기서 새 필터를 만들지 않는다(§4 판정선 기준 그대로 "미확인"
으로 기록).

## 해석 — accel(56·57)과 같은 패턴

이번이 leader-forward 대리 측정으로 잰 **두 번째** 진입 필터 후보고, 첫 번째
(가속도)와 마찬가지로 **가설이 예상한 방향이 나오지 않았다**(하나는 무신호,
하나는 반대). `47-limitup-lock-preregistration.md`가 일봉으로 이미 내린 결론
("엣지는 규칙이 아니라 판단·호가에 있다")과 같은 방향으로 다시 확인된다 —
장중 미시구조 필터 두 개를 규칙화해봐도 대장 자신의 forward 지속력을
높이지 못한다.
