# 뉴스·재료 텍스트 소스 조사 — LLM 태깅을 붙일 수 있는가

> 2026-08-23. 읽기 전용 조사(에이전트). 결론: 1년치 종목 뉴스를 프로그램으로 합법 확보할 경로는 없다. 현실 경로 = DART 공시 원문(무료·즉시) + 빅카인즈 엑셀 수동.


목표: 2025-08 ~ 2026-08 **종목별 뉴스 텍스트** 1년치를 LLM 태깅(재료 강도·테마)에 쓸 수 있게 확보하는 경로.

## 1. 레포·형제 레포에 이미 있는 것

### scalp-it — 코드는 반쯤, 데이터는 0
- `src/scalp_it/news/` = 계획 2(뉴스 인제스트)의 **입력 무관 부분만** 구현돼 있다: `dedupe.py`(제목 자카드 클러스터링), `hotness.py`(기사수 급증·매체수·거래대금 3축, 가중치 0.4/0.3/0.3 고정), `calendar.py`(휴장일 기사 → 다음 거래일 이월), `store.py`(로컬 sqlite `data/news.db` 스키마: `articles(news_id,date,outlet,title,body,keywords,orgs,url)` / `article_codes(news_id,code,match_kind)` / `daily_news`).
- `src/scalp_it/adapters/news_db.py` = 위 sqlite 읽기 어댑터(`load_articles`, `load_article_cards`), `features/news.py`·`features/llm.py`·`cli_layers.py`가 이걸 소비. `features/llm.py`엔 LLM 피처 캐시 테이블과 provider 호출(httpx 직접) 골격이 있음(`--provider fake`로만 검증됨).
- **미구현(실물 파일 필요)**: 빅카인즈 엑셀 파서(`news/bigkinds.py`·`schema.py`), 기사→종목 매퍼(`news/mapping.py`), `cli_news.py`. 계획 문서: `docs/archive/superpowers/plans/2026-08-17-news-ingest.md`, `HANDOFF.md` "아직 안 된 것".
- **데이터 파일 없음**: `data/news.db`·`data/bigkinds/` 둘 다 존재하지 않음. `.gitignore`의 항목은 계획 단계에서 미리 넣은 것. 8/17 스펙에 "2만 건 실물 실측"이 적혀 있으나(아래) 파일은 남아 있지 않다.
- 스펙(`docs/archive/superpowers/specs/2026-08-17-swing-it-design.md` §4 rev2)에 **이미 한 번 재본 결론**이 있다:
  - 빅카인즈 웹 다운로드: 본문 200자, 1회 20,000건 상한, **요청 기간 앞부분이 잘린다**(8/10~8/17 요청에 8/10·8/11 소실 실측) → 3년치 "수동 36회+".
  - 실측(2만 건): 경제 기사 50.1%가 상장사 언급, 이벤트 종목 기사는 전체의 6.6%, 매체·분류·키워드 어느 축으로도 부피를 못 줄임.
  - 뉴스토어 API: 10년·전문·**유료 견적제**. `krx-news-rest-api`(자체 레포, GitHub에만 있고 로컬엔 없음): Redis TTL 1h, 과거 없음.
  - 정책: "직접 크롤러를 새로 짜지 않는다(네이버·언론사 ToS·저작권, 공개 전환 계획과 충돌). 빅카인즈 자동화도 안 한다."

### 형제 레포
- `kr-quant`·`quant-airflow`·`quantbox`: 뉴스 관련 코드 없음(grep 히트는 `naver_consensus`·`naver_supply_demand`·`naver_delisted_bars` 수집기 — 네이버 금융 **시세/수급/컨센서스** 크롤이지 뉴스 아님). 단, 이 수집기들이 이미 `finance.naver.com/item/frgn.naver`·`m.stock.naver.com/api/stock` 을 치고 있다는 사실은 기록해 둔다(robots.txt상 Disallow 경로).
- `gpt_quant/news_parser`: **미국** 주식(Tiingo 뉴스 + OpenAI 분석, nasdaq small caps). 한국 뉴스 무관.
- `kiwoom-client`(자체): 186개 엔드포인트 전부 열거돼 있고 뉴스 없음(아래 3).

## 2. DB·DART 현황
- **TimescaleDB(kr_quant)**: public 스키마 14개 테이블 — `consensus, credit_balance, daily_bars, daily_bars_adjusted, delisted_stocks, earnings, minute_bars, sector_index, shares_outstanding_history, short_selling, stocks, supply_demand, theme_groups, theme_members`. **뉴스·공시 본문 테이블 없음.** title/body/content 류 컬럼도 없음.
- **DART sqlite** (`data/`): 스키마는 셋 다 동일 `disclosures(rcept_no, rcept_dt, code, corp_name, corp_cls, report_nm, material_type, is_correction)` — **제목(report_nm)+분류만, 본문 없음.**
  - `dart_full.db` 716,698건 2016-09-01~2023-12-29 / `dart_2024.db` 335,179건 2024-01-02~2026-08-14 / `dart.db` 18,951건 2026-07-01~08-14.
  - **2025-08-01~2026-08-14: 147,692건, 2,650종목.** material_type 분포: 행정 25,321 · 내부자 21,740 · 정기보고 18,151 · 지분변동 17,804 · 기타 17,678 · 자본조달 16,646 · 주주환원 7,078 · 실적 6,332 · 공급계약 5,087 · 재량공시 4,886 · 악재 3,176 · 구조조정 2,636 · 시설투자 829 · 기술_인허가 328.
  - `adapters/dart.py` 는 `list.json` 만 쓴다. `document.xml`(원문 zip) 호출은 **아직 안 짜여 있음**(스펙엔 적혀 있음). 키 3개 × 일 20,000콜 → 1년치 전체 원문 147k건이면 약 2.5일, 재료성(실적·공급계약·기술_인허가·시설투자·구조조정·악재·재량공시 ≈ 23k건)만이면 반나절.

## 3. 키움 REST API — 뉴스 엔드포인트 없음 (확인)
- 공식 가이드(openapi.kiwoom.com/m/guide/apiguide) 카테고리 OAuth·국내주식·미국주식 전부 훑어도 이름에 뉴스·공시가 들어간 API 없음. 종목정보는 ka10001/ka10099/ka10100(기본정보·종목 리스트)뿐.
- 자체 래퍼 `kiwoom-client` README 지원 목록 186개(계좌33·종목정보31·시세25·주문8·신용4·차트21·순위23·업종6·기관외국인4·공매도1·대차4·테마2·조건검색4·ELW11·ETF9 + 실시간19종)에도 뉴스 없음. 스펙에도 "뉴스 엔드포인트는 없음"으로 적혀 있음.
- 따라서 **호출해 볼 ID 자체가 없다**(크레덴셜 미사용). 과거 히스토리 여부는 질문 자체가 성립 안 함.

## 5. LLM 태깅 비용 자릿수
가정(추측): 빅카인즈 기준 경제면 1년 ≈ 120만 건, 상장사 언급 50% → **(기사,종목) 행 ≈ 60만**; 이벤트 종목만(6.6%) ≈ **8만**. 입력은 제목+200자 본문+키워드 ≈ 300자 ≈ 400토큰(한글 1자≈1~1.5토큰, 추측) + 지시문 ~500토큰(캐시) → 건당 입력 ~1,000·출력 ~100토큰. 단가(2026-06 캐시 기준): Haiku 4.5 $1/$5, Sonnet 5 $3/$15(8/31까지 $2/$10), Opus 5 $5/$25 per 1M; Batch API −50%, 프롬프트 캐시로 지시문 −90%.

| 범위 | Haiku 4.5 | Sonnet 5 | Opus 5 |
|---|---|---|---|
| 이벤트 종목 8만 건 | ~$120 → **십수만 원**(배치 ~6만 원) | ~$360 → **수십만 원** | ~$600 → 수십만~백만 원 |
| 상장사 언급 전수 60만 건 | ~$900 → **백만 원 초반**(배치 ~60만 원) | ~$2,700 → **수백만 원** | ~$4,500 → 수백만 원 |
| 뉴스토어 전문(≈2,000토큰/건)이면 | 위의 ×2~3 | | |

→ **자릿수: 이벤트 종목만·Haiku/배치면 수만~십수만 원, 전수·Sonnet이면 수백만 원.** 데이터 확보보다 LLM 비용은 작다.

## 결론 한 줄
**가장 빠르고 합법적인 경로는 "DART 원문(무료·즉시) + 빅카인즈 엑셀 수동 다운로드(회원·무료·재배포 금지, 5일 단위 약 70회 클릭)" 이고, 1년치 종목 뉴스를 프로그램으로 그냥 긁어올 합법 경로는 없다** — 키움 REST엔 뉴스 API가 없고, 네이버 검색 API는 백필이 안 되며, 네이버 금융 종목뉴스 API는 종목당 2,000건 캡에 robots 전면 금지(스펙 정책 위반), 빅카인즈 Open API는 기관 승인제, 뉴스토어·인포맥스는 유료다. 파서·매퍼·CLI(계획 2 Task 1·2·4·7)는 엑셀 1개만 있으면 바로 짤 수 있게 설계가 남아 있다.
