# 사전등록 (62번) — 섹터 대장 선정 (52주 신고가 다수 섹터)

> 2026-09-06 작성, **측정 전 커밋**. `54-implementation-backlog.md` §2-5, 출처 침착해
> `52-three-engine-spec-v9.md` 모듈 A-1. 표본·신호·라벨·판정선을 여기서 고정한다.

## 0. 왜 이걸 재나 — 그리고 06번 6차와 뭐가 다른가

52번 원문 A-1:

```
- Dominant Sector Identification:
  * Rank sectors by Macro Tailwind (...) + Multi-Stock 52-week Highs [00:00:00], [00:20:54].
```

**06번 6차 사전등록("주도 섹터")과 헷갈리기 쉬워 먼저 구분한다.** 06번 6차는 "당일 섹터
평균 등락률"·"최근 20일 섹터 수익률"·"섹터 평균 대비 개별 등락률" 3종을 **종가베팅
규칙에 필터로 얹어** 봤고 셋 다 기각됐다("재현 불가능한 것이 만쥬의 진짜 기술이다").

이번 항목은 **다른 신호, 다른 대상**이다: 종가베팅에 필터를 얹는 게 아니라, **"그
섹터에서 52주 신고가를 찍는 종목이 여럿인가"라는 breadth(폭) 신호 자체로 섹터를
고르고, 그 섹터의 대장주를 직접 사는** 독립 가설이다. 06번 6차는 이 신호를 쓴 적이
없다 — 신고가 breadth 는 이번이 처음이다.

## 1. 표본 — 측정 전 고정

```
유니버스     stocks.sector 가 있는 상장 종목 전체 (27개 섹터, load_stock_master)
             폐지 종목은 섹터 없어 제외 → 생존편향 방향 (06번 6차와 동일 한계)
기간         daily_bars_adjusted 전체 11년
신고가 정의   당일 종가 >= 직전 250거래일(당일 제외, shift(1)) 최고 종가
섹터 breadth  그 섹터에서 당일 신고가를 찍은 종목 수 (당일 상장·거래된 종목 기준)
지배 섹터     breadth >= 3 (원문 "Multi-Stock" — 복수를 뜻하므로 2 초과인 가장 작은
             정수 3을 쓴다. 자연스러운 경계이지 탐색으로 고른 값이 아니다)
대장 선정     지배 섹터 내 신고가 종목 중 당일 등락률(종가/전일종가-1) 최고
유동성 하한   대장의 당일 거래대금 >= 50억 (프로젝트 기존 하한, dip_events.py 와 동일)
```

**다른 breadth 임계(2, 4, 5)·다른 신고가 기간(120일, 500일)은 시도하지 않는다.**

## 2. 피처 — 없음, 순수 이벤트 스터디

분류 모델을 쓰지 않는다. "지배 섹터의 대장을 사면 같은 기간 시장 평균보다 나은가"
하나만 잰다.

## 3. 모델 — 진입·청산 하나만

```
진입   트리거일 종가
청산   10거래일 뒤 종가 (프로젝트의 수급-지속성류 팩터가 쓰는 5~20거래일 보유의
       중간값 — `22-lowfreq-factor-scout.md` 참고. 다른 N 은 시도하지 않는다)
비용   왕복 34bp 기본, 55bp 보수 병기
비교   같은 기간 유니버스 전체의 무조건부 10거래일 수익률 평균(기준선) 대비
```

## 4. 분할 — 시간 순

11개년 연도별로 나눠 보고한다. 무작위 분할 없음.

## 5. 판정선 — 측정 전 고정

**AND, 전부 만족해야 채택(추가 조사 가치):**

1. net34(34bp 차감) 평균 > 0
2. 11개년 중 음수 해 ≤ 2개
3. 상위 1% 제거 후에도 net34 평균 > 0
4. 승률 > 50%
5. **기준선(같은 기간 유니버스 무조건부 10일 수익) 대비 net34 가 더 낫다** — 이게
   "섹터 대장 선정이 무조건부 시장 평균 이상의 정보를 주는가"를 직접 묻는 조건이다

**하나라도 못 넘으면 기록하고 접는다. 파라미터를 바꿔 재시도하지 않는다.**

## 6. 통과하면 무엇을 하나

06번 관행 그대로 — **실전 투입 아님.** 통과해도 그림자 배선 → 전진 기록 → 별도
승인 절차. 이 문서는 측정 단계만 다룬다.

## 해석 — 두꺼운 우측 꼬리가 전부다

전체 평균(+1.22%)은 기준선(+0.27%)을 이기지만, **중앙값은 −2.37%로 대장 매수의 57%가
손실**이다. 상위 1%(약 118건)를 걷어내면 평균이 +1.22%에서 −0.25%로 뒤집힌다 — 소수의
대박(아마 신고가 돌파 후 상한가로 이어진 케이스)이 전체 평균을 끌고 가고 나머지
다수는 진다. 06번 6차·47번 굳힐대장 판별에서 반복된 것과 같은 패턴: **평균만 보면
속는다.**

"52주 신고가 breadth 로 지배 섹터를 고르고 그 안 등락률 1위를 산다"는 신호는
**분산이 큰 복권**이지 안정적 엣지가 아니다. 재시도 없음.
