# PEAD 결합 오버레이 사전등록 — 롱 다리 살리기 (25번)

> 2026-08-23. **측정 전 커밋.** 23·24번에서 PEAD 롱숏 채택(50억 롱숏 net +4.47%, t=6.15).
> 단 **엣지는 숏 다리**에 있다: 롱온리 Q10 초과수익은 50억 t=3.83, 500억 t=0.48(사실상 소멸).
> 이 문서는 **PEAD 데실 위에 얹을 오버레이 3개**를 사전등록한다. 목적: **롱 다리를 살리거나
> 롱숏 엣지를 강화**. 측정은 `scripts/verify_pead_overlay.py` 로 **사전등록 그대로 1회**.
> 규율: 진입·데실 정의는 23·24 그대로 `pead_events.build_events` 재사용, **오버레이만 추가**.
> 각 오버레이는 **하나의 사전등록 규칙**(조합 탐색·임계 재탐색 금지). 판정선은 아래 고정, 측정 후 불변.

## 0. 묻는 것

**23·24의 PEAD 롱숏 위에 결합 신호(수급·모멘텀·초기반응)를 얹으면 약한 롱 다리가
살아나거나(고유동성서도 net>0 & t>2), 롱숏 t 가 개선되는가.**

## 1. 공통 기반 (23·24 재사용)

- 이벤트 구성: `pead_events.build_events` — earnings.avail_date PIT, 영업이익 YoY SUE
  `(oi−oip)/|oip|`, 진입 = avail 익일 시가, 상한가·스팩 제외, 상폐주 포함.
- 데실: **분기(period)내 횡단면** sue_raw 데실(Q1..Q10). 전역 풀링 금지.
- **유니버스 = 배포 스펙 50억**(진입 직전 20일 평균 거래대금 ≥ 5,000백만). 24번 배포선.
- 라벨: 진입 시가 → +40거래일 익일 시가(주보유). 비용: 왕복 34bp/다리, 숏차입 +40일 0.5%p.
- 롱 = Q10, 숏 = Q1, 동일가중. 롱숏 = Q10−Q1 분기 스프레드 시계열, t = N분기.
- **매칭 베이스(matched base):** 각 오버레이는 진입시점·부분표본이 다를 수 있으므로,
  **같은 부분표본·같은 진입·같은 유니버스에서 필터 없는 전체 Q10**을 함께 계산해
  오버레이 효과만 격리한다. (전역 23·24 숫자와 직접 비교 아님.)

## 2. 오버레이 (측정 전 고정 — 각 1규칙)

### 오버레이 1 — PEAD × 수급 (supply_demand)
- **가설:** 서프라이즈 큰(Q10) 종목 중 avail 근방 **외국인+기관 순매수가 이어지는** 종목만
  롱으로 남기면, 스마트머니 확인으로 롱 다리가 고유동성서 살아난다.
- **데이터 제약:** `supply_demand` 는 2024년부터 2,653종목(그 전은 ~650 대형주뿐, 실패 #2
  유니버스 시프트). → **avail_date 연도 ≥ 2024 폴드로 제한**(명시적 부분표본).
- **룩어헤드 방어(시프트 주의):** avail_date 는 법정마감 일괄부여 → 실제 공시는 그 며칠~몇 주
  전. 따라서 **avail_date 로 끝나는 직전 20거래일** 창의 순매수는 (a) 실제 공시 후 반응
  구간이면서 (b) 진입(avail 익일 시가) **전에 이미 알려진 값** → 룩어헤드 0.
- **규칙:** 창 = avail_date 이하 마지막 20거래일. `net_fi = Σ(foreign_ + institution)`.
  Q10 중 **net_fi > 0**(외인+기관 순매수)인 종목만 롱. 숏 다리(Q1)는 그대로.
- **부호 주의:** supply_demand 값은 순매수(양수=순매수). 창에 20거래일 데이터 없으면 제외.

### 오버레이 2 — PEAD × 모멘텀 (12-1)
- **가설:** Q10 중 추세가 이미 살아있는(12-1 모멘텀 상위) 종목만 남기면 드리프트가 강하다.
- **PBR 불가 명시:** `earnings` 에 자본·순자산 컬럼 없음, 별도 재무제표 테이블 없음
  (public 테이블 전수 확인) → **PBR 계산 불가. 사전등록대로 모멘텀만 사용.**
- **규칙:** 12-1 모멘텀 `M = adj_close[진입idx−21] / adj_close[진입idx−252] − 1`
  (최근 1개월 스킵, 진입 전 데이터만 → 룩어헤드 0; 252거래일 이력 필요, 없으면 제외).
  각 분기 Q10 안에서 **M 이 중앙값 이상(상위 절반)**인 종목만 롱. 숏(Q1)은 그대로.
- 진입·라벨 = 23·24 그대로(avail 익일 시가 → +40).

### 오버레이 3 — PEAD 드리프트 지속 조건 (초기반응)
- **가설(Bernard-Thomas):** avail 직후 초기 반응이 양(+)인 종목("가격이 이미 반응 시작")만
  남기면 이후 드리프트가 강하다.
- **규칙:** 초기반응 `R0 = adj_close[avail+5] / adj_close[avail_last] − 1`
  (avail_last = avail 이하 마지막 거래일, 갭+5거래일 초기 수익 포함). Q10 중 **R0 > 0** 만 롱.
- **진입 시프트(불가피, 사전등록):** R0 는 avail+5 종가로 확정 → **진입을 avail+6 시가**로
  시프트, 드리프트 라벨 = `open[avail+46] / open[avail+6] − 1`(진입 후 +40거래일). 룩어헤드 0.
- **매칭 베이스:** 같은 avail+6 진입·+40 드리프트로 **필터 없는 전체 Q10**(초기반응 조건이
  드리프트를 강화하는지 격리). 숏(Q1)도 동일 시프트로 병행.

## 3. 판정선 (측정 전 고정)

각 오버레이에 대해 **50억 유니버스**에서:
- **롱 다리(주):** 필터 Q10 롱온리 **유니버스 대비 초과수익 net34 > 0 & t > 2**
  (24번 롱온리 판정과 동형), **그리고** 매칭 베이스(필터 없는 Q10) 대비 **net 상승 & t 비하락**
  → "롱 다리 살아남/강화".
- **또는 롱숏(대안):** 필터 Q10 − Q1 롱숏 **net34 t 가 매칭 베이스 롱숏 t 보다 개선**
  (and net>0) → "롱숏 엣지 강화".
- **채택(오버레이):** 위 둘 중 하나 만족.
- **기각(오버레이):** 둘 다 실패 → 해당 결합은 값 없음.
- **전체 결론:** 3개 중 하나라도 채택되면 **실전 스펙 갱신 제안**(오버레이 반영).
  전부 기각이면 **"PEAD 순수 롱숏이 최선"** 으로 확정.

## 4. 다중검정·한계 (정직)

- **오버레이 3개 시험** 명시. 하나만 유의하면 다중검정 하 우연 가능성 감안(판정문에 명시).
- 각 오버레이는 부분표본(오버레이1: 2024+, 오버레이3: 진입 시프트)이라 **N·검정력이 낮다**
  (특히 오버레이1: 2024+ 50억 Q10 은 분기당 소수). 이는 매칭 베이스와 함께 보고.
- 임계·창길이·상위비율은 **표준값 고정**(20일/12-1/median/5일), 측정 후 재탐색 금지.
- 조합(오버레이 2개 동시)·다른 임계 탐색 금지. 안 되면 순수 롱숏이 최선.
