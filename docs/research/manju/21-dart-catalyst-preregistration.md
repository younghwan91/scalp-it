**형식 기준:** `09-breakout-preregistration.md`·`06-closebet-preregistration.md`. 측정은 이 문서 확정(커밋) 후 1회.

## 묻는 것 (한 문장)

> **돌파·상따 진입 이벤트 중 "직전 K거래일 내 재료성 DART 공시가 있는" 것과 없는 것의 익일 시가
> net34 수익이 다른가 — 즉 재료 필터가, 분봉으로 재현했더니 전부 기각된 이 두 기법을 선별하는가?**

## 왜 이번엔 다른가 — v2 공시층 기각과의 차이 (명시)

아카이브 실패 목록에 **"② 공시 피처층 기각"**이 있다 (`docs/archive/2026-08-17-disclosure-layer-verdict.md`).
거기서 공시 유형·제목 17피처를 얹으니 **① 수급만 +7.61% → ② +공시 +7.32%, −0.29%p** 로 값을 못 했다.
그럼에도 이번을 다시 하는 이유 — **세 가지가 그때와 다르다:**

| | v2 공시층 (기각) | 이번 (21번) |
|---|---|---|
| 지평 | 스윙 D+20~40 드리프트 | **단타 1일 (익일 시가)** |
| 공시의 역할 | 급증 이벤트 위에 얹은 **피처 17개** (ML 이 학습) | 기법 자체 진입 이벤트를 가르는 **선별 필터 하나** (플래그) |
| 인과 방향 | 급증→재료 찾기 = **역인과 위험** | 돌파·상따 진입 **직전(과거)** 공시로 거른다 → 역인과 아님 |
| LLM 본문 | 안 씀 | **이번에도 안 씀** (유형 화이트리스트만). 이게 신호 있으면 **다음 회차에** LLM 이 본문 강도를 읽는다 |

즉 이번은 "재료 유형이 존재하는가"라는 **가장 거친 첫 칸**만 본다. 여기서 신호가 없으면 본문 강도(LLM)로
내려갈 근거가 없고, 있으면 다음 회차 LLM 회수의 착수 근거가 된다.

## 재료성 공시 정의 — **화이트리스트 (지금 고정, 측정 후 변경 금지)**

### 왜 유형 버킷이 아니라 제목 키워드인가

DB 의 `material_type`(14종, `src/scalp_it/dart/classify.py`)은 **단타 재료를 가르기엔 너무 거칠다.**
측정 전 분포 점검(2025-08~2026-08-14, 결과값 아님)에서 확인:

- `자본조달` 버킷 최다가 **투자설명서(일괄신고)·ELS/DLS 일괄신고추가서류** — 증권사 선반등록, 발행사 재료 아님.
- `지분변동` 버킷 최다가 **주식등의대량보유상황보고서(5%룰)** ~1.2만 건 — 루틴. 재료는 `최대주주변경`뿐.
- `구조조정` 버킷 최다가 **타인에대한채무보증** — 재료 아님. 재료는 합병·분할·양수도.
- `재량공시` 최다가 **기업설명회(IR)** — 루틴. 그러나 **임상·품목허가는 `투자판단관련주요경영사항(임상…)`**
  으로 여기(재량공시) 들어온다 — 유형 버킷으로는 못 잡는다.

→ **버킷이 아니라 `report_nm` 제목 키워드로** 화이트리스트를 정한다. 정정·첨부 마커
(`[기재정정]`,`[첨부정정]`,`[첨부추가]`,`[정정]`)는 제거 후 매칭 (원 공시의 재탕도 재료로 인정).

**악재 전부**(롱온리라 못 먹음). 이 목록은 위 키워드에 안 걸려 자동 제외된다.

## 접수시각 처리 — 룩어헤드 방지 (보수)

`rcept_dt` 는 **날짜만** (YYYYMMDD), 접수 **시각**이 없다. 장중 접수인지 장마감후인지 모른다.
따라서 **당일(진입일 D 당일) 공시는 진입 판정에 쓰지 않는다** — 룩어헤드가 되기 때문.

- **주 플래그 `cat_prior`** = 진입일 **직전 K거래일** 창 안에 재료성 공시가 있는가.
  창 = `[D 의 K거래일 전 날짜, D−1(달력)]` — K거래일 사이의 주말 접수도 포함. **D 당일 제외.**
  거래일 달력은 `daily_bars` 의 실제 거래일 집합에서 만든다.
- **K = 3 거래일 (고정).** 만쥬는 "재료 나온 그날/다음날" 을 본다 — 짧게 잡는다.
- **당일 공시 `cat_same`** (rcept_dt == D) 는 **분리 보고만** (룩어헤드 있음, 판정 제외).

## 측정 설계 — 재선별 금지, import

- 돌파: `scripts/verify_breakout.py` 의 이벤트 캐시(`ev`) 를 **그대로** 읽는다 (09번 정의, 재계산·재선별 없음).
- 상따: `scripts/verify_sangtta.py` 의 이벤트 캐시(`ev`) 를 **그대로** 읽는다 (06번 5차 정의).
- 각 이벤트 `(code, date=진입일)` 에 `cat_prior`·`cat_same`·서브유형 플래그를 붙인다.
- **결과 지표 = 익일 시가 net34.**
  - 상따: 등록된 `ret`(= 익일 시가 수익)그대로. net34 = ret − 0.0034.
  - 돌파: 원 규칙은 당일 종가 청산이지만 **이 질문의 지표는 익일 시가**다. 같은 진입 이벤트에
    `daily_bars`(원주가) 익일 시가를 붙여 `ret_nextopen = 익일시가/진입가 − 1` 을 새로 만든다
    (이벤트 재선별 아님 — 청산 지표만 문서 질문에 맞춤). 등록 주 규칙 `ret_stop2`(당일청산)도 **병기**한다.
- **비교:** 재료有(`cat_prior=1`) vs 재료無 의 n · net34 · net55 · 중앙 · 승률 · 월별 폴드.
- **서브유형 분해:** 서브유형별 net34 — **진단이지 판정 아님**(다중검정, 한계 4).
- **상한가 오염 제거:** 상따는 `limit_at_entry`(진입시 이미 상한가 의심) 제외판 병기.
  돌파는 `is_limit_close`(당일 상한가 마감)·`ret_at_trigger≥20%` 제외판 병기 (아카이브 실패 6).

## 판정선 — **미리 못 박는다 (기계적)**

각 기법에 대해, **아래 셋을 전부 만족하면 재료 필터 채택**(전진 기록 착수), 하나라도 실패하면 **기각**:

1. **차이 유의:** 재료有 net34 > 재료無 net34 이고, 부트스트랩(10,000회 재표본)으로
   `mean(有) − mean(無)` 의 95% 양측 신뢰구간이 **0 을 넘지 않는다**(하한 > 0).
2. **월별 안정:** 재료有 이벤트를 진입 월별로 나눠, 이벤트 ≥ 20건인 달만 세어 net34 < 0 인 달이
   **≤ ⌊n_months/3⌋**.
3. **재료有 단독 양(+):** 재료有만으로 net34 > 0 이고, **상한가 오염 제거 후에도** net34 > 0
   (상따=`limit_at_entry` 제외, 돌파=`is_limit_close` 및 `ret_at_trigger≥20%` 제외).

셋 다 통과 → **채택**. 아니면 → **기각.** 판정은 돌파·상따 **각각** 내린다.
서브유형 분해에서 특정 유형이 좋아 보여도 그것만으로 채택하지 않는다(사후 선택 금지, 한계 4).

## 이벤트 규모 (측정 시 채운다)

- 돌파·상따 이벤트 총 n, 그중 재료有(`cat_prior`) 비율, 당일 공시(`cat_same`) 비율.
- 서브유형 분포 (재료有 이벤트 중 각 서브유형 건수 — 한 이벤트가 복수 유형이면 중복 계수, 명시).
- DART 창(2025-08~2026-08-14) 과 분봉 이벤트 창(~2026-08-21) 의 갭 → 마지막 5거래일은 재료無로
  잘못 분류될 수 있음 (한계 5).

스크립트: 이벤트 규모 조사 `scripts/dart_catalyst_events.py`, 측정 `scripts/verify_dart_catalyst.py`.

## 한계 (측정 전 명시)

1. **접수시각 룩어헤드** — `rcept_dt` 는 날짜만. 당일 공시를 제외해 회피하지만, K거래일 창 안의
   공시도 "장마감 후 접수 → 사실상 익일 재료"일 수 있어 창이 실제보다 하루 어긋날 수 있다.
2. **DART ≠ 전체 재료** — 테마·뉴스·풍문·수급 이벤트는 공시로 안 남는다 (17번). 재료無 중 상당수가
   "공시 아닌 재료"가 있는 종목일 수 있다 → 재료有/無 대비를 **희석**(귀무 쪽 편향)한다.
3. **화이트리스트의 임의성** — 키워드·서브유형 선택은 우리가 정했다. 측정 후 변경 금지로 사후조정은
   막지만, 처음부터 잘못 골랐을 위험은 남는다.
4. **다중검정** — 서브유형별 분해는 진단이다. 유형 하나가 유의해 보여도 다중검정 보정 없이는 채택 근거가
   아니다. 판정은 오직 위 3조건(전체 재료有 vs 無)으로만.
5. **창 경계** — DART 데이터가 2026-08-14 까지라, 분봉 이벤트 창(~08-21)의 마지막 며칠 이벤트는
   재료有인데도 재료無로 잡힐 수 있다. 해당 구간 이벤트 수를 보고한다.
6. **재료有 표본 크기** — 재료 필터는 정의상 이벤트를 줄인다. 재료有 n 이 작으면 부트스트랩 검정력이
   낮다 — n 을 보고하고, 작으면 "미확정"이 아니라 판정선 미달 = **기각**으로 처리한다(전진 기록만 채택).
