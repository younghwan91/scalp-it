# 42 — 짝꿍 재최적화 선결 조건 (지금은 만들지 않는다)

> **판정: 지금 재최적화는 무의미.** 병렬 감사(reopt-audit)와 착수 프로토타입의 실측이
> 같은 결론에 도달했다. 데이터가 2거래일뿐이고(08-24 종일 + 08-25 킬스위치로 절단된
> 부분치), 등록 쌍 4개, 셀당 체결 n 한 자릿수 → **OOS 성립 불가·다중검정 유의성 0.**
> 스크립트·cron 은 **만들지 않는다.** 아래 6조건이 갖춰진 뒤에 만든다.

## 왜 지금은 안 되나 (프로토타입 실측)

착수해 감지기(`PairDetector`)로 이벤트를 재생성하고 그리드(진입 18 × 청산 36)를 돌려본
결과, 재최적화가 **적극적으로 오도(誤導)한다**는 증거만 나왔다:

1. **표본.** `ticks` 에 08-24(260k)·08-25(75k, 09:41 절단) **단 2일.** 트레인 1일·홀드아웃
   1일 → OOS라 부를 수 없다. 트레인 최선 셀(through·touch 모두)이 **홀드아웃에서 부호까지
   뒤집혀 재현 실패.** 그리드 "최선"은 doc38 이 경고한 사후선택 착시 그대로였다.
2. **비용.** 운영 데몬은 `cost_rate` 기본 **0.0** 으로 굴러 `pair_positions.log` 손익이
   **세전·스프레드 무시**다(doc35 스프레드 실측 25~38bp: 후속주 002990 0.13% / 094480 0.22%
   / 294570 0.28% / 033340 0.36%). 세후 0.18%+스프레드를 빼면 through pooled net ≈ **−0.5%**,
   현행 셀도 through −0.44%. 로그를 그대로 최적화하면 타이트 익절이 2배 과대평가된다.
3. **낙관 편향.** 미완결 포지션을 MFE(순행 최대)로 청산(항상 +), 손절 무슬리피지, 킬스위치가
   그리드 평가 중 작동해 나쁜 셀의 뒤쪽 이벤트를 잘라 성과를 부풀린다.
4. **구현 취약성.** 프로토타입에서 손절값 부호 하나(그리드는 크기, 시뮬은 부호)만 어긋나도
   손절선이 진입가 **위**로 가 매 체결 즉시 발동 → "손절 −0.7% 승률 100%" 같은 완전한
   허깨비가 나왔다. n이 작을수록 이런 버그가 그럴듯한 숫자로 위장한다. **검증 없는 재최적화 =
   버그를 엣지로 착각하는 기계.**

## 재최적화를 만들어도 되는 선결 조건

1. **수십 거래일 축적.** 최소 20~30 거래일 이상, 쌍당 체결 이벤트 수십 건. 그전엔 셀별 n이
   한 자릿수라 어떤 argmax도 노이즈다.
2. **비용 실측 반영.** 세금+수수료(세후 0.18%)에 **종목별 실측 스프레드**를 더해 net을 계산.
   운영 데몬도 실비용을 로그에 남기도록(현행 `cost_rate=0.0` 탈피) 하거나, 재생성 시 스프레드를
   틱에서 실측해 차감.
3. **킬스위치는 라이브 전용.** 그리드 평가에서는 킬스위치·동시보유상한을 **끄고** 모든 이벤트를
   독립적으로 채점한다(가드는 실전 손실통제 장치지 백테스트 필터가 아니다).
4. **진짜 홀드아웃.** 마지막 구간을 완전히 격리하고, 파라미터 argmax는 **트레인에서만** 수행한
   뒤 홀드아웃에 단 한 번 적용해 재현 여부만 본다. 홀드아웃을 보고 셀을 고르면 OOS가 아니다.
5. **보수적 청산.** 미완결 포지션은 MFE가 아니라 **마지막 관측가**로 청산, 손절·시장가 청산에
   **슬리피지**(스프레드/틱)를 반영. through(보수)를 실전 기대선으로 본다.
6. **멱등.** 로그 append 누적이 아니라 **틱 재생 기반**으로 매 실행이 같은 입력에 같은 결과를
   내야 한다(부분치·재수집·정정에 강건).

## 그때까지

`pair_detect_daily.sh`(장중 감지·수집) + `pair_daily_summary.py`(15:25 집계)로 **며칠 더
관측만** 누적한다. 조건 1(수십일)이 충족되면 이 문서의 2~6을 설계 기준으로 재최적화 도구를
만든다. 그전까지의 어떤 "최선 파라미터"도 착시이므로 **현행 유지**(감지기 stable 기본:
서지 1.5% · 프리무브 0.2% · 매수비율 0.30 · 익절 +0.5% · 손절 −0.4% · 90초).
