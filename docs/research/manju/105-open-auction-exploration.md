# 105 — 개장 동시호가 → 첫 1·5·15분 탐색 (2026-10-05)

> [104](104-event-driven-search-frame.md) 의 첫 탐색. 기술(description)이며 사전등록이 아니다.
> 스크립트 `scripts/explore_105/run.py`, 테스트 `tests/test_explore_105.py`.

## 0. 질문

개장 단일가(09:00)에 사서 첫 1·5·15분 안에 팔 때 수익이 비용을 넘는 **전일 정보만으로 만든** 조건이 있는가.
[97](97-universe-diagnosis.md) 은 시가→종가(상위 300 −28.0bp/일)만 봤고, 첫 15분의 갭 지속/반전 동역학은 안 쟀다.

## 1. 자료·정의 (코드 짜기 전에 고정)

- 분봉 `minute_bars` 2025-08-01~2026-10-02. **진입가 = 09:00 행 `open`**(개장 단일가 체결가로 본다).
  **청산가 = 09:01 · 09:05 · 09:15 행 `close`**(그 분이 비면 직전 분의 close). 보유 1분은 보고만, 판정은 5·15분.
- 일봉 `daily_bars` 로 **전일** 값: 종가·거래대금·수익률·고가·20일 변동성. 전일 행과 당일 사이 달력 7일 넘게 비면 버린다.
- 유니버스: 전일 종가 ≥ 1,000원인 종목 중 **전일 거래대금 상위 1,300**. `research/bad_days.json` 날짜 제외.
- 조건 변수는 전부 전일 값. **갭(09:00 체결가/전일 종가 − 1)은 09:00 체결 뒤에야 아는 값이라 진입 조건으로 쓰지 않는다** — 보고용 분해에만.
- 비용(종목별, 라벨에서 한 번 뺀다) = 세금 20 + 수수료 3 + 개장 동시호가 스프레드 절반 + 연속세션 스프레드 절반.
  daytrade-it 실측(97 §4b): 개장 동시호가 거래소 19.1 / 코스닥 30.7, 연속 세션 14.0 / 19.1.
  → **거래소 39.55bp · 코스닥 47.9bp.** 시장은 `stocks.market`.

## 2. 판정 셀 6개 (코드 짜기 전에 적음, 바꾸지 않는다)

전일 수익률(유니버스 안 당일 분위) **상위 10% / 하위 10% / 중간(10~90%)** × 보유 **5분 / 15분**.

각 셀: 평균·중앙·양(+) 비율 · **매치드 널 alpha**(`krx_quant_core.stats.matched_null`, 층 = 날짜 × 전일 20일 변동성 4분위 ×
전일 거래대금 4분위, 풀 = 그날 유니버스 1,300 전체, 대조 1:1, 자기 자신 제외) · 날짜 클러스터 95% CI · 월별 부호.

**기각 기준(미리 고정)**: 6셀 전부 널 alpha CI 하한 ≤ 0 이면 105 는 닫힌다.

보고용(판정 아님): 보유 1분 · 갭 10분위 × 보유 · 상한가성(전일 종가 = 전일 고가 ∧ 전일 수익률 ≥ 28%) · 시장별.

### 3.3 결론 (한 문단)

개장 단일가에 사서 첫 1·5·15분에 파는 어떤 전일 조건 셀도 비용은 물론 0 도 넘지 못한다. 전일 급등 상위 10% 는 유니버스 안에서도
−25bp 더 나쁘고(널 alpha CI 상한 −16), 하위 10% 는 유니버스와 같다(alpha ≈ 0). 중간 셀의 +2.6 / +3.3bp 는 꼬리의 여집합일 뿐 절대
수익은 −57 / −63bp 다. 갭 분해는 첫 분부터 갭 반전이 단조로 진행됨을 보여 주고, 가장 덜 잃는 칸(갭다운 1분 −13.5bp)도 사후 정보다.
97 의 일중 −28bp 드리프트는 개장 15분에 이미 그 두 배(−60bp 전후, 비용 포함)가 나 있다 — 첫 15분은 "다른 동역학"이 아니라 같은 드리프트의
가장 가파른 구간이다.

**양수였다면 사전등록했을 것**: 전일 하위 10% × 5분(유일하게 alpha 점추정 양수·CI 가 0 을 걸침)을 전진 구간(2026-10 이후)에서 alpha CI 하한 > 0 ·
절대 평균 > 0 둘 다로 재는 사전등록 — 지금 수치(절대 −64bp)로는 쓰지 않는다.

### 3.4 데이터 한계

- **일봉과 분봉이 기업행동 뒤 서로 다른 재수집 창에서 키움 수정주가로 덮여 2·5·10배 어긋난다**(006050 10:1 병합 — 분봉이 ×10 수정주가로
  덮였고 일봉엔 이음매; 연속인 건 `daily_bars_adjusted` 뿐. 정정본은 [104](104-event-driven-search-frame.md) §데이터 결함).
  1차 실행은 전일 종가를 일봉으로 썼고 갭·1,000원 필터가 오염돼 폐기했다(원장에 남김). 2차는 전일 종가를 **전일 분봉 15:30 종가**로 바꿨다 —
  09:00 open 과 같은 테이블·같은 재수집 창이라 유일하게 자기일관적이다. 1,000원 필터도 같은 값으로 근사했다; "그날 실제 호가 단위"는
  틱(2026-08-24~)만 믿을 수 있어 그 전 구간은 근사다. 09:00~09:15 수익률(같은 날 분봉끼리)·전일 수익률·상한가성(일봉끼리)은 영향 없다.
  판정 라벨(분봉 09:00 open → 분봉 close)은 두 실행에서 같은 식이라 셀 값은 거의 안 움직였다 — 1차: 상위 10%/5분 −93.6(alpha −24.9) ·
  하위 10%/5분 −65.4(+2.8) · 중간/5분 −59.0(+2.8), n 263k. 2차와 차이는 유니버스 구성(아래)에서 왔다.
- 유니버스는 사실상 **분봉이 수집된 2,097종목 안의 전일 거래대금 상위 1,300** 이다(1차는 일봉 3,100종목에서 1,300 을 뽑은 뒤 분봉 있는 것만 남겨
  일당 943). 일봉에만 있는 종목(ETF·수집 밖)은 어느 쪽에서도 안 들어간다.
- 09:00 행 `open` 을 개장 단일가 체결가로 봤다. 09:00 분봉이 없는 종목·날(개장 체결 없음)은 사건이 아니다 — 체결 여부로 정의된 조건부지만 매수
  쪽이라 "살 수 없었던 날"을 뺀 것이고, 수익에 유리한 선택은 아니다(갭업 큰 날은 대개 체결이 있다).
- 청산가는 해당 분 close(그 분이 비면 직전 분 close) — 시장가 매도 체결가가 아니라 분 종가다. 스프레드 절반을 비용에 넣어 보정했지만 체결 모형은 아니다.
- 기간 14개월(2025-08~2026-10), 국면 하나. 월별 부호가 15/15 음수라 국면 의존은 아니지만 2022 급 국면은 안 들어 있다.
- 모든 수치는 1주 기준(97 §5b).
