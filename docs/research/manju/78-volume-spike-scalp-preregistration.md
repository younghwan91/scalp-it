## 3. 트리거 — 1분봉 t (봉 라벨 시각)

```
시간      09:05 ≤ t ≤ 15:00, 그날 봉을 분 격자로 펴고 빈 분은 거래량 0
기준선    base(t) = max( mean(vol[t−20 .. t−1]) — 그날 앞 봉이 5개 이상일 때,
                         D−1 일 거래량 / 390 )
거래량    vol(t) ≥ K × base(t)
돈        trade_value(t) ≥ 1억원
가격      close(t) > open(t)  AND  close(t)/close(t−1) − 1 ≥ R
런웨이    close(t) ≤ 상한가 − 5호가  (상한가 = limit_up_price(D−1 원주가 종가))
쿨다운    같은 종목은 앞 거래 청산 봉 이후에만 다음 트리거(겹침 없음)
```

격자(6셀): **K ∈ {3, 5, 10} × R ∈ {+0.5%, +1.5%}**. 전부 우리 값이다.

## 4. 진입·청산 — 분봉 근사, 스톱 우선

`tk(p)` = 가격 p 의 호가단위(`scalp_it.ticksize.tick_size`).

```
진입    e = open(t+1) + 1호가     (t+1 봉 없거나 e ≥ 상한가면 거래 없음)
스톱    S = e − 1호가             (B-2 "진입가 또는 −1틱")

진입봉 j = t+1   (봉 안 순서를 모르고, 스톱선이 시가라 저가로 판정하면 100% 손절이 된다.
                  그래서 진입봉만 종가로 본다)
   close(j) ≤ S                → 손절, 청산 close(j) − 1호가
   high(j)  < e + 1호가         → 본절탈출(안 뜸), 청산 close(j) − 1호가
그 뒤 봉 j = t+2 … t+10  (한 봉 안에서는 스톱을 먼저 본다)
   low(j) ≤ S                  → 손절, 청산 S − 1호가
   close(j) < close(j−1)       → 파동 소진(첫 하락 분), 청산 close(j) − 1호가
   j = t+10 또는 15:19 봉       → 시간, 청산 close(j) − 1호가
```

매도 −1호가는 매수1호가에 던지는 것의 근사다.

### 4-1. 비용

- **현실 1주(주 판정)**: 위 호가단위 슬리피지 + `round_trip_cost(D, 시장, commission_rate=0.00015)`.
- **크기 반영(서술)**: 라이브 명목 1,000만원. 편도 추가 충격 = σ₁ × √(1,000만 / trade_value(t)),
  σ₁ = (high(t) − low(t)) / open(t). 제곱근 법칙, 계수 1 은 우리 값. 판정에 안 쓴다.
- 서술 병기: 전 봉 종가 판정(낙관 쪽) 결과.

3. 날짜 클러스터 부트스트랩(10,000회, seed 78) 평균 95% CI 하한 > 0.
4. **무작위 대조를 이긴다**: 거래마다 같은 종목·같은 날 09:05~15:00 에서 무작위 분 t′ 하나

7. 상위 1% 제거 평균 > 0.

## 11. 미리 밝히는 한계

- **1분 해상도.** 타 트레이더 B의 "1~2틱·첫 하락 틱"은 초 단위다. 진입봉은 종가로, 이후는 스톱 우선으로
  근사한다. 둘 다 실제와 다르다. 틱 검산(§8)이 방향만 보여 준다.
- **체결 가속·뭉친 시장가**를 거래량 배수로 대신한다. 매수/매도 방향 체결이 분봉에 없다.
- 검색순위 Top3·일간 50% 반납·40/60 분할을 재현하지 못한다.
- minute_bars 종목 목록의 사후 선정 가능성(생존 편향)이 있다.
- 무작위 대조가 같은 종목·같은 날이라 "그날 급등주였다"는 정보를 공유한다. 대조를 이긴다는
  것은 "그날 안의 타이밍" 가치만 뜻한다.
