## 핵심 발견
- **지정가(bid1) 진입 = 시장가 대비 net +0.15%p** (청산보다 큰 레버). 비용 세후 0.18%(세금0.15+수수료0.03), 스프레드는 체결가 내재.
- **청산: 고정 TP +0.8% / 90초** 가 최선. 트레일 최악(소형주 노이즈, 승률 15~25%). 60초 단순홀드 폐기 정당.
- **결정적 필터 = 리드랙**: 후속주가 직전 30초 +0.2% 이하(아직 안 뜀)일 때만 진입 → 세후 **+0.27%(체결시)/+0.18%(신호당), 승률 75%**. 이미 뛴 후속주=추격(꼭지)=마이너스. 경제논리 분명.

## 실전 최소 규칙 (일반화, 소액)
```
진입: 대장주 30초 +1.5% 서지 → 동반급등 후속주 중 직전30초 ≤+0.2%(안뛴것)만
      → 후속주 bid1 지정가 매수(15초 미체결 취소)
청산: +0.8% 지정가 익절 / 90초 시간청산 (트레일 금지)
```

## 정직한 경고
하루치·이벤트82·최선셀 체결 n=10~24·사후 쌍+사후 필터 → **유의성 없음.** 상한가 잠김 0건(만쥬 강한형태 미검증). 진실 세후 +0.05~0.18% 약한 양(+) 추정, 증명 불가. **소액 실전으로 체결률·역선택 실측 필요. 소액 이상 금지.** through(보수) 체결선에선 +0.05%(n10)로 급감 — 미체결·역선택이 최대 리스크.


> **결론**: 지정가(bid1) 진입은 시장가 대비 net을 **+0.15%p** 끌어올린다(엔트리 스프레드 절감 — 청산 최적화보다 큰 레버). 이걸로 **시장가·60초홀드의 명백한 마이너스(-0.24%)를 손익분기 근처로 올림**. 최선 셀(bid1 지정가 + TP+0.8% + 90초)은 낙관 체결가정에서 세후 **+0.03%(체결시)·+0.02%(신호당)**, 보수 체결가정에서 **-0.13%**. → **엣지가 비용을 명확히 넘지는 못함.**
> **단 하나 각도가 남음**: 후속주가 **아직 안 뛴**(직전 30초 ≤+0.2%) 이벤트만 진입 = "리드랙 지정가" → 세후 **+0.27%(체결시)·+0.18%(신호당)**, 승률 75%. 경제적으로 말이 됨(추격 아님, 선행). 그러나 **n=24 체결·하루·사후 쌍·사후 필터** → 유의성 없음. 보수 체결선 +0.05%(n=10)로 쪼그라듦.
> **판정**: 지금 데이터론 "확실히 양(+)"이라 부를 조합 없음. 가장 가까운(그리고 경제적으로 그럴듯한) 규칙은 **리드랙 지정가**. 며칠~2주 더 필요, 특히 상한가 잠김 날.

데이터: 어제(08-24) ticks 179.5만·quotes 101.9만, 4쌍 doc36 그대로. 비용 = 세금 0.15%+수수료 0.03% = **세후 0.18%**. 스프레드는 bid/ask 실체결가에 내재(이중계상 안 함). 이벤트 = 대장 직전 30초 ≥+1.5% 서지, 60초 디둡. 이벤트 총 82(인디에프31·더즌20·아이티센14·금호전기17).

## 1. 지정가 진입 체결확률 (진입 후 15초 내)
| 쌍 | 이벤트 | bid1 지정가 체결 | bid1+1틱 체결 |
|---|---|---|---|
| 인디에프→좋은사람들 | 31 | 58% (touch) / 32% (through) | 77% / 58% |
| 더즌→갤럭시아 | 20 | 75% / 40% | 95% / 75% |
| 아이티센→쿠콘 | 14 | 64% / 21% | 71% / 64% |
| 금호전기→금호건설 | 14 | 100% / 79% | 100% / 100% |
| **pooled** | 79 | **71% / 40%** | 85% / 75% |

- **touch**(가격이 지정가에 닿으면 체결 = 낙관, 큐 맨앞 가정) vs **through**(가격이 지정가를 뚫어야 = 보수, 큐 뒤). 현실은 사이.
- bid1+1틱은 체결 잘 되나(75~100%) net이 나쁨(1틱 더 냄). bid1이 net 최선.
- **핵심 함정 = 역선택**: through에서 체결률 71%→40%로 붕괴, 그리고 체결되는 건 "후속주가 안 따라와서 가격이 내게 내려온" 약한 이벤트 → net도 같이 나빠짐.

## 2. 청산 최적화 — 진입모델별 세후 net% (pooled, 체결분, touch)
| 청산 | 시장가 진입 | **bid1 지정가 진입** |
|---|---|---|
| 60초 단순홀드(baseline) | -0.24% (win35%) | -0.09% (win46%) |
| 고정 TP +0.3% | -0.24 (65%) | -0.06 (80%) |
| 고정 TP +0.5% | -0.20 (53%) | -0.06 (66%) |
| **고정 TP +0.8%** (M90) | -0.11 (54%) | **+0.03 (62%)** ← 유일 양(+) |
| 트레일 고점-0.2% | -0.32 (15%) | -0.12 (21%) |
| 트레일 고점-0.3% | -0.32 (16%) | -0.13 (25%) |
| 3:3:4 분할 | -0.23 (47%) | -0.06 (55%) |

- **청산 서열**: 고정 TP > 분할 > 단순홀드 >> 트레일. 트레일은 소형주 노이즈에 휩쓸려 승률 15~25%(최악).
- **TP 스윕**: 작은 TP(0.2~0.3%)는 승률 80~84%지만 승자를 너무 일찍 끊어 net↓. **+0.8%가 스윗스팟**(우측 꼬리 포착). horizon은 **M90 > M60 > M30**(팝이 발달할 시간).
- **지정가 진입이 청산보다 큰 레버**: 시장가는 어떤 TP·horizon에서도 양(+) 없음(최선 -0.11%). 지정가로 바꾸면 같은 청산이 +0.14%p 개선.
- 후속주 MFE(지정가 체결분, M90) 중앙 +0.95%·p75 +1.43% → **파동은 실재**(팝은 온다). 문제는 세후 0.18% 바닥 + 역선택을 넘기는 것.

## 3. 손익분기 판정
| 조합 | 체결모델 | 세후net(체결시) | 신호당(×체결률) |
|---|---|---|---|
| bid1 + TP0.8% + 90s (전이벤트) | touch | +0.030% | +0.021% |
| 〃 | through | -0.13% | -0.09% |
| **bid1 + TP0.8% + 90s, premove≤0.2% 필터** | **touch** | **+0.267%** | **+0.178%** |
| 〃 | through | +0.052% | +0.015% |

- 전(全)이벤트로는 **낙관 가정에서만 겨우 0 위**, 보수 가정에선 음수 → **명확한 손익분기 돌파 아님**.
- **premove 필터(후속주가 직전30초 ≤+0.2%만 진입)** 가 유일하게 비용을 뚜렷이 넘김: touch 신호당 +0.18%·승률 75%(n=24 체결/36 진입가능). 경제 논리 분명 — 대장과 **같이 이미 뛴** 후속주를 사면 추격(꼭지), **아직 안 뛴** 걸 사면 선행. doc36이 "평균 리드랙 없음"이라 한 걸 **조건부(라거드만)로는 리드랙이 살아있음**.
- 단 보수 체결선 +0.05%(n=10)로 급감 = 여전히 역선택 취약. 진실은 +0.05~+0.18% 사이 → 아마 **약한 양(+)**, 유의성은 없음.

## 4. 60초 홀드 대비 개선 (요약)
시장가·60초홀드 -0.24% → (지정가 진입) -0.09% → (+TP0.8%/90s) +0.03% → (+premove필터) +0.18%. 총 +0.42%p 이동, 그중 **지정가 +0.15 / 청산+horizon +0.12 / premove필터 +0.15**.

## 5. 실전 최소 규칙 (잃어도 작게)
사람이 칠 수 있나 — **진입은 쉬움**(지정가는 수동으로 걸어둠), **대장 서지 감지·발주는 자동 필요**(30초 +1.5%). 청산도 TP 지정가+시간청산이라 반자동 가능.

**"리드랙 지정가" 최소 규칙** (가장 가까운 양(+) 조합, 소액 테스트용):
1. 대장(어제 검증쌍: 인디에프·더즌·아이티센·금호전기) 직전 30초 **+1.5% 서지** 감지.
2. 그 순간 후속주가 **직전 30초 +0.2% 이하로 아직 안 뛰었으면**만 → 후속주 **bid1 지정가 매수**(15초 내 미체결이면 취소·스킵).
3. 청산: **+0.8% 지정가 익절**, 안 닿으면 **90초 시간청산**(bid 시장매도). 트레일 금지.
4. 기대: 세후 신호당 **+0.05~+0.18%**(체결모델 밴드), 승률 ~75%, 하루 4쌍에서 수 회.

주의: **아주 작게**. n=24(하루·사후) → 실수익 검증 아님. 이 규칙으로 며칠 실체결 로그를 쌓아 체결률·역선택 실측이 목적이지, 지금 돈 버는 규칙이라 믿으면 안 됨.

# 갱신 — 손절 확정 + "쌍 큐레이션" 진실 (2026-08-24 재검)

`pairgen.py`·`pairgen2.py`.

## 손절 (사용자 질문 답)
60초 단순홀드 폐기하고 손절 넣어도 양(+) 유지:
| 청산 | 세후/거래 | 승률 | 손익비 | 체결 |
|---|---|---|---|---|

## 결정적 진실: 완전 자동 후속선택은 실패
대장 서지마다 "동반급등 & 안 뛴 것 중 최고" 를 **기계로** 고르면 세후 **−0.11~−0.21%·승률 21~31%.**
이유: 그렇게 고르면 이미 꼭지 눌린 강한 종목을 삼. 만쥬 후속 = 대장 뒤따르는 **더 작은** 종목인데 기계가 구분 못 함.
→ **엣지는 "대장 → 알려진 소형 후속" 특정 관계에서만.** 관계 기계발굴 실패(테마 얇음·상관=섹터베타, doc36).
**후속 쌍 목록은 사람이 미리 큐레이션. = 만쥬가 실제 하는 방식.**

## 실전 형태 (확정)
- **규칙 형태(진입 트리거·지정가·−0.3% 손절 청산)는 종목 무관 = 일반화.**
- **후속 쌍 목록은 손으로 유지.** 시작 쌍: 인디에프→좋은사람들 · 더즌→갤럭시아 · 아이티센→쿠콘 · 금호전기→금호건설.
- 감지기는 "전체 자동 매칭" 아니라 **"등록한 쌍만 감시"**.
- 목적: 지금 돈벌이 아니라 실체결 로그로 체결률·역선택·쌍 안정성 실측. 소액. 상한가 잠김 날 더 강할 개연(어제 0건).

# 손절 재판정 — 두 에이전트 상반, 정교한 쪽 채택 (2026-08-24)

`pairstop.py`. pair-limit 은 "−0.3% 손절 넣어도 +0.09% 양+", stop-calibrate 은 "손절 넣지 마라, EV 반토막".
**둘 다 −0.3% 가 EV 를 깎는 데는 일치.** 차이는 해석. stop-calibrate 논거가 더 정교해 채택:

- **bid1 지정가 = 눌림매수 → 진입 후 역행 얕음** (MAE 중앙 −0.29%, p90 ≈ 0%, 최악 −1.48%). 손실 절반이 진입방식으로 이미 방어.
- **−0.3% 손절은 50% 가 스프레드(25~38bp) 노이즈에 튕겨 발동** → +0.8% TP 까지 살아 돌아올 트레이드를 작은 손실로 확정(승률 75%→62%).
- 모든 손절선이 EV 반토막(무손절 +0.267% → −0.3% +0.189 / −0.5% +0.138). 손절이 사주는 건 MDD(최악 1건) 0.3~0.5%p 뿐.
- through(역선택) 체결선: 손절 전부 음수, 무손절만 +0.05% → **손절이 역선택 리스크 증폭.**

## 확정 청산 (감지기 기본값)
- **일상 손절: 없음.** 손절은 이미 둘 — **bid1 지정가(얕은 MAE) + 90초 시간청산.** 90초 청산이 곧 손절.
- **재난 방지선: −0.7%** (스프레드 밖, 발동 21%, EV −0.12%p 만, 갭·상한가 잠김 날 폭탄 방지). **−0.3~0.5% 절대 금지**(노이즈 반토막), −1.0% 무의미(갭 관통).
- 익절 +0.8%(공격형) 또는 +0.5%(보수형), 90초 시간청산.

**경고:** 하루치·체결 24·through 10·상한가 잠김 0건. MDD 전부 단일 트레이드. "타이트 손절이 EV 죽인다"는 확실, "−0.7% 최적 재난선"은 약한 제안 — 소액 실전 MAE 로 확정.

# 손절 수렴 — 상반 아니라 선호 차이 (2026-08-24 최종)

- **공통 사실:** −0.3~0.4% 손절은 MDD 캡(−1.27→−0.74%)·손익비↑(0.81→1.2)·승률 안정 — 하지만 세후 EV 를 소폭 깎음(+0.27→+0.19%). bid1 눌림매수라 MAE 얕고(−0.29%), 손절 50%가 스프레드 노이즈에 튕김.
