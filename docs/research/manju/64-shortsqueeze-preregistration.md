그 측정에 쓰인 **정확한 스크립트·파라미터를 찾으려 시도했다** —
`git log --all` 전체·`data/`·스크래치 파일을 뒤졌으나 **커밋된 스크립트를 찾지
못했다** (다른 세션의 미커밋 스크래치였던 것으로 보인다).

**따라서 이 문서는 "재검증"이 아니라 사실상 첫 정식 사전등록이다.** 08-30 숫자를

독립적으로 다시 뽑았다. 08-30 결과와 방향이 비슷하면 참고가 되고, 다르면 그것도
정직하게 기록한다.

> 일봉 + 수급 | ✅ 바로 측정 가능")

## 1. 표본 — 측정 전 고정

```
데이터    daily_bars_adjusted (일봉) + supply_demand (수급)
기간      2024-01-01 ~ 2026-08-21   (*)
유니버스  supply_demand 보유 종목만 (약 630종목 — 2024년 이전은 커버리지 없음,
          06번 문서 2차 사전등록과 같은 제약)
거래대금  당일 거래대금 >= 50억 (백만원 단위 5,000 — 이 프로젝트 기존 하한,
          종가베팅·낙주와 동일 값, 새로 고른 값 아님)
```

(*) `supply_demand` 가 2024-01 부터 630종목만 있다는 제약(`universe-shift.md`)을
그대로 따른다. 11년 전체와 비교하지 않는다.

**트리거 정의:**
```
52주 신고가   당일 종가가 직전 250거래일 최고 종가 이상 (06번 "+신고가" 조건과 동일 정의)
연속 순매수   외국인 순매수(foreign_) > 0 그리고 기관 순매수(institution) > 0 인
             날이 트리거일 포함 최근 3일 연속 (트리거일이 마지막 날)
선택         하루 여러 건이면 전부 포함 (종가베팅처럼 "하루 2건" 제한 두지 않음 —
             표본이 이미 작아서 인위적 축소를 하지 않는다)
```

**"연속 3일"은 사후 정보 없이 고른 값이다.** 원문이 "consecutive accumulation"만
말하고 일수를 특정하지 않아, 자연 경계값 중 최소치(연속의 최소 조건인 3일)를
잡았다. 2일/5일 등 다른 값은 시도하지 않는다.

## 2. 피처 — 없음 (분류 모델 없음)

이번 회차는 06번 5차·10번처럼 분류 모델을 적합하지 않는다. 트리거 정의 자체가
전부이고, 트리거 발생 시 **전부 매수**의 성과만 본다 (종가베팅 1차 확정과 같은 성격).

## 3. 모델 — 하나만

```
진입   트리거일 다음 거래일 시가 (익일 갭업을 노리는 것이므로 시가 매수)
청산   진입일(=트리거 다음날) 종가  — "엣지가 전부 갭에 있다"는 원가설을 그대로
       시험한다: 시가에 사서 그날 종가에 파는 것으로 "갭 이후 하루 보유분"을 본다.
비용   왕복 34bp 기본, 55bp 보수 병기
```

**다른 진입·청산 조합을 시도하지 않는다.** "트리거일 종가 매수 → 익일 시가 매도"
(순수 갭만) 등 변형은 이번 회차에서 하지 않는다 — 왜냐하면 원문이 "익일 갭업에
베팅"이라 했고, 갭업에 베팅한다는 건 갭이 나기 **전에** 사서 갭을 받는 것이 아니라
갭이 확인된 뒤에도 상승이 이어지는지를 보는 것이 이 프로젝트의 관행("종가에 살 수
없다" 문제, 06번 참조)과 맞다. 즉 "시가 매수 → 당일 종가 매도"가 실행 가능한
유일한 형태다.

## 4. 분할 — 시간 순

기간이 2024-01~2026-08 로 약 2.5년뿐이다. 연도별 대신 **분기별** 음수 구간 수를
본다 (약 10분기).

## 5. 판정선 — 측정 전 고정

**채택 조건, AND 로 전부 만족:**

1. 34bp 차감 후 평균 > 0
2. 분기(≈10개) 중 음수 분기 ≤ 3개 (11년/2개 조건의 비율을 분기 스케일로 근사)
3. 상위 1% 제거 후에도 34bp 차감 평균 > 0
4. **상한가 마감 의심 종목 제외해도** 34bp 차감 평균 > 0 — 06번 "⚠️ 채택 철회"가
   이 프로젝트를 한 번 태운 바로 그 함정(수익이 전부 상한가 마감에서 나오는 것)을
   미리 막는다. 상한가 의심 = 트리거 다음날 종가 등락률 ≥ +29.5%
5. 승률 > 50%

**하나라도 못 넘으면 기록하고 접는다. 파라미터를 바꿔 재시도하지 않는다.**

## 6. 통과하면 무엇을 하나

06번 관행 그대로: **실전 투입 아님.** 채택은 그림자 배선·전진 기록 착수를 뜻하고
실제 매매 판단은 그 이후 별도 승인을 거친다.

## 08-30 요약치와의 비교

08-30 요약(기준선 +0.02% → 셋업 +0.56%, 승률 47%)과 방향부터 다르다 — 이번
정의로는 셋업 자체가 34bp 전 평균도 −0.22%로 음수다. §0 에서 밝혔듯 08-30 의
정확한 스크립트를 찾지 못해 원인을 특정할 수 없다. 짐작 가는 차이:

- 08-30 은 아마 "기준선"(무조건부) 대비 "셋업"(조건부)의 **상대적 개선**만
  봤을 수 있다 — 이번 정의는 셋업 자체의 절대 수익을 5조건으로 판정했다.
- 진입·청산 정의가 다를 수 있다(예: 트리거 종가 매수 → 익일 시가만 보는
  "순수 갭" 정의였을 가능성). 이번 문서는 "시가 매수 → 당일 종가" 로,
  갭 이후 하루 종일의 되돌림까지 포함한다.

**상한가 오염은 없었다**(1건/2,695, 0.04%) — 06번을 태운 함정은 이 정의에서는
재현되지 않았다. 순수하게 "52주 신고가 + 외인·기관 3일 연속 순매수" 조합
자체에 익일 갭업 지속 엣지가 없다는 결론이다.

**재시도 없음.** 이 정의(3일 연속·시가매수→당일종가)로는 기각. 다른 연속일수·
다른 청산(예: 익일 시가만)을 시도하려면 별도 사전등록이 필요하다.
