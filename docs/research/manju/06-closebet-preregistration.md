# 사전등록 — 종가베팅 최종 판정

**작성 시각:** 2026-08-17, 최종 측정 **이전**
**대상:** 만쥬 6대 기법 중 **종가베팅** (D 종가 매수 → D+1 시가 매도)

## 지금까지 무엇을 봤는지 먼저 적는다

정직하게 자유도를 계상한다. 이 판정 전에 본 것:

1. **스파이크 (04번 문서)** — 규칙 5개를 훑었다. 등락률 10%+ 조건이 상한가를 끌어와
   무효였다. **판정에 쓰지 않는다.**
2. **엔진 스모크** — 규칙 `tv_ratio>=3.0 & close_pos>=0.8` 1개. 이 규칙은 결과를
   보기 전에 지정했다.
3. **꼬리·유동성·집중도 진단** — 상위 제거 6단계, 거래대금 5분위, 하루 N건 6단계.
   **여기서 본 것이 아래 파라미터 선택에 영향을 줬다.** 그 사실을 숨기지 않는다.

따라서 아래는 **완전한 사전등록이 아니라 사후 정보가 일부 들어간 확정**이다.
**최종 신뢰는 전진 검증으로만 얻는다.**

## 확정 규칙 — 이 하나만 측정한다

```
유니버스   당일 거래대금 >= 50억
스캔       tv_ratio >= 3.0        (거래대금 / 직전 20일 평균, shift(1))
           close_pos >= 0.8       ((종가-저가)/(고가-저가))
순위       tv_ratio 내림차순
선택       하루 상위 2건
진입       D 종가 (15:20~15:30 동시호가 단일가)
청산       D+1 시가 (09:00 동시호가 단일가)
비용       왕복 34bp (2026년 기준, 03번 문서)
```

### 파라미터 근거

| 값 | 근거 | 사후 정보 여부 |
|---|---|---|
| `tv_ratio >= 3.0` | 엔진 스모크 전에 지정 | **아니오** |
| `close_pos >= 0.8` | 엔진 스모크 전에 지정 | **아니오** |
| 거래대금 50억 | Q1(중앙 2억)만 net 음수(−0.42%). 그리고 **이 프로젝트가 PEAD 때부터 쓰던 기존 하한과 같은 값**이라 새로 고른 값이 아니다 | 부분적으로 예 |
| 하루 2건 | 만쥬의 실제 매매 빈도(하루 1~2건대)와 개인 계좌 자본 제약. 성과곡선이 1→26건에서 **단조 감소**라 2가 특별히 좋은 지점이 아니다 — 1건이 더 높지만 표본이 절반이라 2를 쓴다 | 부분적으로 예 |
| 비용 34bp | 03번 문서의 "기본" 시나리오 | 아니오 |

**다른 값은 시도하지 않는다.** `tv_ratio` 2.5/4.0, `close_pos` 0.7/0.9, 하루 3건 등을
돌려 더 나은 것을 고르지 않는다.

## 보고할 것

평균만 보지 않는다 (지금까지의 교훈):

- n, 하루 건수, **평균·중앙값**, 승률, **손익비**
- 분위 p5/p25/p75/p95, 최소·최대
- **연도별 전체** (11개년) — 음수 해가 몇 개인가
- **비용 4단계** (0 / 21bp 낙관 / 34bp 기본 / 55bp 보수)
- **상한가 의심 건수와 제외 시 결과**
- **상위 1% 제거 후 평균** — 꼬리 의존도
- 다음날 봉 없어 제외된 건수 (거래정지·상폐)

## 판정 기준 — 미리 정한다

**채택(전진 검증 착수) 조건, 전부 만족해야 한다:**

1. 비용 **34bp** 차감 후 평균 > 0
2. **11개년 중 음수 해 ≤ 2개** (34bp 차감 후 기준)
3. 상위 1% 제거 후에도 34bp 차감 평균 > 0
4. 상한가 의심 건 전부 제외해도 34bp 차감 평균 > 0
5. 승률 > 50%

**하나라도 못 넘으면 기록하고 종가베팅을 접는다.** 파라미터를 바꿔 재시도하지 않는다.

## 채택되더라도

**실전 투입은 아니다.** 이 프로젝트는 백테스트를 세 번 믿었다가 두 번 틀렸다
(Minervini 아티팩트, 스윙 ①층 중복매수). 채택은 **전진 기록 착수**를 뜻하며,
실제 매매 판단은 전진 데이터가 쌓인 뒤에 한다.

## 남은 미검증 리스크 (측정 전에 적어둔다)

- **동시호가 체결 가정** — 15:30 단일가에 시장가로 들어가면 종가에 체결된다고 가정한다.
  실제로는 내 주문이 단일가를 밀 수 있다. 소액이면 무시 가능하나 규모가 커지면 아니다.
- **오버나이트 리스크** — 밤사이 악재에 손절이 불가능하다. p5 가 얼마나 나쁜지 봐야 한다.
- **1년 뒤 시장 구조 변화** — 2026년 증권거래세 인상이 이미 반영됐는지 확인 필요.

## 표본 제약 — 미리 밝힌다

`supply_demand` 는 **2024년 전에 630종목뿐**이다(`universe-shift.md`).
따라서 `+수급` 은 **2024-01 이후로만** 측정한다. 기준 규칙도 같은 기간으로
다시 재서 **동일 기간 비교**한다. 11년 결과와 직접 비교하지 않는다.

`+신고가` 는 일봉만 쓰므로 11년 전체로 측정한다.

## 판정

# 3차 사전등록 — 스승 청산 규율 적용 (측정 이전)

**근거:** 만쥬의 스승 스승의 **문서화된** 규칙
(`07-teacher.md`, 2015·2016년 저서 챕터 제목에서 확인):

- **목표 +2% 이상**
- **손절 −2% 칼손절**
- **이틀 이상 보유하지 않음**
- 물타기 금지

내가 만든 값이 아니라 **출처가 있는 규칙**이라 시험할 자격이 있다.
현재 종가베팅은 D+1 시가에 무조건 청산이라 이 규율이 들어갈 자리가 없다.

## 비교할 청산 3종 (진입 규칙은 1차 확정 그대로)

| 이름 | 청산 |
|---|---|
| `시가` | D+1 시가 (**현행 기준**) |
| `2%관리` | D+1 장중 — 고가가 진입가×1.02 도달 시 **+2%**, 저가가 ×0.98 도달 시 **−2%**, 둘 다 아니면 D+1 종가 |
| `D+1종가` | D+1 종가 (관리 없이 하루 더 보유) |

**일봉 근사의 한계를 미리 밝힌다.** 일봉 OHLC 로는 고가·저가 도달 **순서를 알 수 없다.**
둘 다 닿은 날은 **보수적으로 손절이 먼저 닿았다고 가정**한다. 실제보다 나쁘게 나오는
방향이므로, 그래도 개선되면 신뢰할 수 있다.

**다른 임계는 시도하지 않는다.** +3%/−1%, +2%/−1% 등 변형 금지. 출처에 있는
+2%/−2% 하나만 본다.

## 판정

- 현행(`시가`)보다 **34bp 차감 후 평균**과 **연도별 음수 해**가 모두 나아져야 채택.
- 아니면 현행 유지. 기록하고 끝낸다.
