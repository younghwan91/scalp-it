# 한국 주식 단타 6대 기법 — 정량 규칙 조사

조사일: 2026-08-17
목적: 각 기법을 자동화 가능한 형태(스캔 조건 → 진입 트리거 → 청산 → 손절)로 정량화하고, **필요 데이터 주기**를 확정해 수집 계획의 입력으로 쓴다.

## 이 문서를 읽는 규칙

- 표의 모든 숫자에는 출처 URL이 붙어 있다. 출처 없는 숫자는 넣지 않았다.
- 출처가 서로 다른 숫자를 말하면 **범위로 기록하고 충돌을 명시**했다.
- 내가 자료에서 직접 확인하지 못하고 논리적으로 채운 값은 **[추정]** 으로 표시했다. 백테스트 전까지 신뢰하면 안 된다.
- 대부분의 출처는 **개인 블로그·커뮤니티**다. 검증된 백테스트가 아니라 "시중에서 이렇게들 말한다"의 수집이다. 유일한 통계 성격 자료는 §1의 요일별 야간수익률뿐이며 그마저 표본·방법론이 공개되지 않았다.

### 1.4 필요 데이터 주기

| 용도 | 필요 데이터 |
|---|---|
| 전략 코어(종가 매수 → 시가 매도) 백테스트 | **일봉만으로 가능** — OHLCV + 거래대금이면 전체 재현 가능 |
| 스캔 조건 중 "12:00/14:30 시점 거래대금 순위" | **분봉 필요** (누적 거래대금 시계열) |
| 15:10~15:19 분할매수 체결가 재현 | **분봉 필요** |
| 15:20 동시호가 진입 버전 | **일봉으로 충분** (체결가 = 당일 종가) |
| 시간외 단일가 손절 | 시간외 체결 데이터 필요 (별도 소스) |

**결론: 일봉만으로 1차 검증 가능한 유일한 기법.** 분봉은 진입 시각 최적화 단계에서만 필요하다.

**틱·호가 필수.** 목표 +0.31% / 손절 -0.15% 는 대형주 호가 1~2틱 수준이다. 1분봉 OHLC로는 체결 순서를 알 수 없어 **손절과 익절 중 무엇이 먼저 닿았는지 판정 불가** — 백테스트가 원리적으로 부정확해진다. 게다가 호가 스프레드·수수료·거래세(매도 시)가 목표 수익과 같은 자릿수라 **비용 모델 없이는 무의미**하다.

**판단: 6개 기법 중 자동화 우선순위 최하위.** 데이터 비용이 가장 크고 검증 신뢰도가 가장 낮다.

**수집 계획 함의**

1. **일봉만으로 즉시 착수 가능: 종가베팅, 돌파매매** (+ 상따의 익일 모멘텀 변형). 추가 데이터 투자 없이 검증 시작 가능.
2. **1분봉이 열리면 추가되는 것: 갭매매, 낙주매매.** 1분봉은 종목×390분/일 규모 — 코스피+코스닥 전 종목이면 하루 약 100만 행 수준 [추정]. 저장은 감당 가능하나 수집 채널 확보가 관건.
3. **틱·호가는 스캘핑·상따 전용.** 두 기법 모두 정량 근거의 질이 가장 낮고 비용 모델 민감도가 가장 높다. **호가 수집은 후순위로 미루는 것이 합리적**이다.
4. **공통 필수 부가 데이터**: 거래대금(누적 및 시점별), 시가총액, VI 발동 이력, 상하한가 도달 여부. 특히 거래대금은 6개 기법 전부의 1차 스캔 필터다.
