# 틱 스캘핑 1차 sanity — 사전등록 (28번)

> 2026-08-24 작성, **측정 전 커밋**. 신호·라벨·판정선을 여기서 고정한다.
> 하루치(내일 첫 깨끗한 하루)로 도는 **sanity check**이지 확정 판정이 아니다.
> 확정은 며칠~몇 주 더 쌓은 뒤 별도 문서로 한다. 다중검정·과최적화를 경계한다.

## 0. 가설 (만쥬 초단타의 엣지)

"체결이 바바박 들어오는(체결강도 급증·매수 체결 우세) 순간에 진입하면 **다음 수 분간
오른다**." 이걸 `ticks`(체결) 로 처음 검증한다. `docs/research/manju/20` 참고.

## 1. 신호(트리거) — 측정 전 고정

각 종목·정규장(09:00~15:20), 각 체결틱 `t` 를 후보로 본다. `t` 로 끝나는 **직전 W초**
윈도에서:

- `mean_strength_W` = 그 윈도 체결강도(228) 평균
- `buy_ratio_W` = Σ(volume where side=+1) / Σ(volume)  (매수 체결 비율)
- `n_W` = 윈도 내 체결 건수

**트리거 = 두 조건을 동시에 만족:**
1. `mean_strength_W ≥` 그 **(종목·당일)** 의 `mean_strength_W` 분포 **80분위**  (체결강도 급증)
2. `buy_ratio_W ≥ 0.60`  (매수 체결 우세)

게이트·독립성:
- 활동 게이트: `n_W ≥ 5` (한두 건짜리 얇은 체결 배제)
- **쿨다운**: 트리거 발생 후 그 종목은 다음 `max(N)=120초` 동안 새 트리거를 억제(라벨 구간
  겹침으로 인한 중복 카운트 방지 → 사건 근사 독립).

**고정 파라미터(조합 폭발 금지):**
- 윈도 `W ∈ {30, 60}` 초 (2개)
- 강도 분위 `P = 80`, 매수비율 `B = 0.60`, 활동게이트 `K = 5` — **단일값 고정**

## 2. 라벨 — 측정 전 고정

- 진입가 = 트리거 틱 체결가.
- 지평 `N ∈ {30, 60, 120}` 초.
- `MFE_N` = (구간 (t, t+N] 최고 체결가 / 진입가 − 1)  — 최대 유리 이동
- `ret_close_N` = (t+N 이하 마지막 체결가 / 진입가 − 1)  — 지평 종료 수익
- **비용(스캘핑)**: 왕복 40~60bp 가정. 기본 표기 **50bp**, 40/60bp 병기.
  `net_close_N = ret_close_N − cost`.

## 3. 비교군

1. **트리거군 vs 비트리거군**: 같은 종목·같은 장의 비트리거 틱(종목별 매칭 표본)에서
   동일한 forward N초 `MFE`·`ret_close` 를 잰다.
2. **분위별 단조성**: `buy_ratio_W` · `mean_strength_W` 각각 **5분위**로 나눠 분위별
   forward N초 평균 수익. 상위분위 > 하위분위(단조 증가) 여부.

## 4. 판정선 — **측정 전** 고정

"**신호 있음 → 며칠 더 쌓아 확정**" 으로 본다. 아래를 **모두** 만족할 때:

- (방향) 트리거군 forward 수익(MFE·close)이 비트리거군보다 **높다** — 차이의 부트스트랩
  CI(1000회)가 0을 넘지 않고 부호가 양(+).
- (비용 후) 어떤 `(W,N)` 조합에서든 `net_close_N ≥ 0` (50bp 기준).
- (단조성) 강도·매수비율 상위분위 forward 수익 > 하위분위.

**"신호 약함"**: 비용 후 `net_close_N ≤ 0` 이거나 방향이 양(+)이 아님.

주의: **하루치라 t·CI 는 참고**다. 방향과 **효과크기**(bp) 위주로 읽는다. 오늘(2026-08-24)
데이터는 데몬 초기 thrash 가 섞여 불완전하니 스크립트 "돌아가는지"만 보고, 실제 판정은
내일부터의 깨끗한 하루 자동 실행(평일 16:00 cron) 결과로 한다.
