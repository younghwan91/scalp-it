# 104 — 이벤트 구동 탐색 프레임 (2026-10-05, 사용자 지시로 재개)

> 사용자: "에이전트를 풀어서 스캘핏 방식으로 트레이딩 방안이 없는지 모색해서 자율적 코딩 진행해."
> 102 로 **무조건부·연속 시간** 현물 일중은 종결됐다. 남은 가능성은 **이벤트에 조건화된 순간**뿐이다 — 이벤트 순간은
> 움직임이 비용(41.5bp)보다 클 수 있고, 지금까지 한 번도 이벤트 기준으로 자르지 않았다.

## 모든 탐색이 지키는 규칙 (95~103 에서 값을 치르고 배운 것)

1. **순위·필터는 전일 값만.** 당일 거래대금 순위는 부호를 뒤집는 look-ahead 였다(+71.9 → −28.0bp).
2. **수집 불량일 제외** — `research/bad_days.json`.
3. **대용값이 아니라 실물.** 지수 대용 −16.6bp(t=−4.28)가 실제 ETF 에서 −5.0bp(t=−1.59)였다.
4. **매치드 널 필수** — `krx_quant_core.stats.matched_null`(day × 시각 × 전일 변동성 4분위 × 전일 거래대금 4분위).
   무조건부 평균은 보고만 하고 판정에 쓰지 않는다.
5. **체결 여부로 정의된 부분집합은 표본이 아니라 조건부**(딥 체결 −7.4bp, 재시도 체결 −134bp).
6. **셀을 고르면 그게 탐색이다.** 판정 셀은 코드 짜기 전에 문서에 적는다. 나머지는 보고만.
7. **시행 원장** — `krx_quant_core.stats.trials.record_trial(label, config, logs_dir=ROOT/"research"/"logs")`. 누적 N ≈ 2,460.
8. **비용 41.5bp**(연속 세션 테이커). 동시호가 체결이면 daytrade-it 실측(마감 15.1/18.1 · 개장 19.1/30.7bp)을 쓴다.
9. **계산은 simnode 에서만.** trader 에서 돌리면 수집이 깨진다(09-16~18 분커버 50%).
10. **라벨 산술은 테스트 먼저**(미래 안 보기 · 비용 한 번 · 창 정확히).

## 통과하면

사전등록(10x-preregistration) → 잠금 → 전진 → 승격 체크리스트. **탐색 결과로 바로 코딩하지 않는다.**
탐색은 "어디를 사전등록할지"를 정하는 단계다.

## 탐색 중 발견한 데이터 결함 (2026-10-05, 107 → 확인 → quant-airflow 정정)

**처음 판단은 틀렸다.** 나는 "`daily_bars` 가 수정주가"라고 보고했으나, quant-airflow-51 이 주식수 이력으로 확인한 사실은:

- 006050 은 분할이 아니라 **10:1 병합**(2026-09-01, 주식수 34,895,000 → 3,490,000). 병합 전 실제 체결가가 ~500원이므로
  `daily_bars` 의 3월 1,593 이 **원주가**가 맞다.
- 어긋난 쪽은 **`minute_bars`** 다. `adapters/kiwoom.py` 가 ka10080 을 `upd_stkpc_tp="1"`(수정주가)로 부르고 분봉 크론이 매일
  6페이지를 재수집하므로, 기업행동 뒤 재수집된 구간은 키움이 ×10 해서 돌려준 수정주가가 기존 행을 덮었다. 그래서
  분봉 15:30 15,930 은 "병합 후 수정주가"지 그날 체결가가 아니다.
- `daily_bars` 도 같은 종류의 **이음매**가 있다(일봉 수집도 `upd_stkpc_tp="1"`, 15일 창 덮어쓰기). 006050 은 08-11 까지 490,
  08-12 부터 4,900.
- **`daily_bars_adjusted` 만 종목별 전체 이력을 매일 전량 재계산해 시계열이 연속이다.**

영향·조치는 같다: 일봉 종가를 분봉·틱과 섞는 계산은 **같은 테이블·같은 재수집 창의 짝**만 자기일관적이므로
전일종가 = **분봉 15:30**. 1,000원 필터처럼 "그날 실제 호가 단위"가 필요하면 **틱**만 원주가다. 102 의 `gap`
(일봉 원주가 vs 분봉 수정주가)은 여전히 오염 의심. 실시간 감지기 `universe.fetch_bars` 의 자가치유 가드(그날 분봉 15:30 과
20% 넘게 어긋나면 분봉 배수로 맞춤)는 **기업행동 다음 날부터** 일봉 창을 수정주가 기준(= 그날 실시간 체결가와 같은 기준)으로
맞춰 주므로 유지한다. 근본 수정은 수집 쪽(`upd_stkpc_tp="0"` 으로 받고 조정은 파생 테이블로만) — 사용자 승인 사항,
quant-airflow 가 올린다.
