# 사전등록 (61번) — 수급 턴어라운드

> 2026-09-06 작성, **측정 전 커밋**. `54-implementation-backlog.md` §2-4,
> 침착해 `52-three-engine-spec-v9.md` A-1 원문 기반. 표본·피처·판정선을 여기서 고정한다.

## 0. 왜 이걸 재나

52번 문서 A-1 원문:

> Institutional/Foreign Order Flow Reversal (수급 턴어라운드 타점):
> When foreign/institutional sellers dump 2 continuous big negative candles (2음봉)
> after a massive inflow, do NOT buy blindly.
> Trigger: Enter on the day when Foreigners/Institutions re-enter with high volume,
> re-absorbing 50%+ of the 1st negative candle.

52번 문서 자체가 "수급 턴어라운드와 섹터 대장은 지금 당장 사전등록·측정이 가능하다"고
명시했고, 필요한 데이터(일봉 + 외인·기관 순매수)를 이미 갖고 있다. 아직 백로그에
미측정으로 남아 있던 항목이다.

**원문에서 못 옮기는 부분을 미리 밝힌다.** "massive inflow"(대량 유입, 2음봉 전
선행 매수세)는 크기·기간이 원문에 없다. 이 사전등록은 이 전제 조건을 **테스트하지
않는다** — 2음봉 이후 재흡수만 본다. 원문의 "10:00~11:00 장중 확인 후 불타기"도
분봉이 필요해 이번엔 뺀다. 즉 이 시험은 원문의 부분집합이며, 기각돼도 "수급
턴어라운드 전체가 틀렸다"가 아니라 "선행 유입·장중 확인 없이도 되는가"만 답한다.

## 1. 표본 — 측정 전 고정

```
데이터    daily_bars_adjusted (가격) + supply_demand (외인·기관 순매수, 주식수 단위)
기간      2024-01-01 ~ 2026-08-28 (supply_demand 는 2024년 전 630종목뿐이라 —
          06번 2차 사전등록과 같은 제약. 2024-01+ 는 2,818종목으로 커버리지 충분)
거래대금  트리거일(D) 당일 >= 500억 (daily_bars_adjusted.trade_value, 백만원단위 50,000
          — 프로젝트 기본 하한, 06번/59번과 동일 기준 재사용. 50억이 아니라 500억을
          쓰는 이유: 이건 스윙 진입이라 다음날 시가 체결이 필요해 유동성을 더 본다)
```

## 2. 이벤트 정의 — 트리거 시점까지의 정보만

```
D-2, D-1   연속 2음봉 (close < open) 이고, 그 이틀 각각 외인+기관 순매수 합 < 0
           (2인 단순 합산 — 프로그램·연기금 등 세부 구분은 안 함)
D          (트리거일) 외인+기관 순매수 합 >= 0.5 x |D-2일 외인+기관 순매도 합|
           ("1st negative candle" = 시간순 첫 번째 음봉인 D-2 로 읽는다. 되흡수
           대상을 D-1(둘째 음봉)로 읽는 대안 해석도 있으나, 원문 "1st" 를 문자
           그대로 따른다 — 다른 해석은 시도하지 않는다)
           그리고 D 당일 거래대금 >= 500억
선택       하루 여러 건이면 전부 포함(만쥬 계열 시험처럼 "하루 N건" 제한 없음 —
           이건 스윙이라 회전율 제약이 약하다)
```

## 3. 모델 — 하나만

```
진입   D+1 시가 (D의 수급 데이터는 종가 이후에나 확정되므로 당일 진입 불가)
청산   D+1 개장 후 10거래일째 종가 (약 2주 — pyproject.toml 이 밝힌 이 프로젝트
       스윙 범위 "2~8주" 중 하한을 고른다. 다른 N(5·20일 등)은 시도하지 않는다)
비용   왕복 34bp 기본, 55bp 보수 병기
```

**다른 임계·기간을 시도하지 않는다.** 재흡수 비율 30%/70%, 거래대금 하한 300억/1000억,
보유기간 5일/20일 등 변형 금지.

## 4. 분할 — 시간 순

2024-01~2026-08 약 2.7년, 11년 시험들처럼 연도별로 쪼개기엔 짧다. 06번 5차·59번과
같은 방식으로 **시간순 3폴드**를 쓴다.

## 5. 판정선 — 측정 전 고정

**채택(추가 조사 가치 있음) 조건, 전부 만족해야 한다:**

1. 비용 34bp 차감 후 평균 > 0
2. 시간순 3폴드 중 음수 폴드 <= 1
3. 상위 1% 제거 후에도 34bp 차감 평균 > 0
4. 승률 > 50%
5. 거래대금 상위 50%만 봐도(대형주 편중이 아닌지) 34bp 차감 평균 > 0

**하나라도 못 넘으면 기록하고 접는다.** 파라미터를 바꿔 재시도하지 않는다.

## 6. 통과하면 무엇을 하나

**실전 투입 아니다.** 채택은 전진 기록 착수를 뜻하며, 이 사전등록이 뺀 부분
("massive inflow" 선행조건·장중 10~11시 확인)을 넣는 후속 사전등록이 별도로 필요하다.

## 해석

**상위 1% 제거하면 평균이 부호를 뒤집는다** — 전체 +0.67%가 소수의 극단값에
의존한다. 승률도 45.7%로 절반 미만이라 "가끔 크게 벌고 자주 조금씩 잃는" 구조다.
손익비 1.33이 이를 상쇄해 전체 net34는 양수로 나오지만, **꼬리 의존도**와
**승률 미달** 두 축에서 동시에 걸려 사전등록 기준을 넘지 못한다.

06번 여러 회차가 보여준 패턴과 비슷하다 — 평균만 보면 그럴듯해도 분위·꼬리를
보면 무너진다. 이 사전등록은 원문의 "massive inflow 선행조건"·"장중 10~11시
확인"을 뺀 부분집합이었다는 점을 §0에서 미리 밝혔다 — 그 두 조건이 지금 실패
원인인 꼬리 의존(선별 없이 아무 재흡수나 다 사면 극단치에 휘둘림)을 줄여줄
가능성은 남아 있으나, **이 사전등록 자체는 재시도하지 않는다** (파라미터를
바꿔가며 재시도하지 않는다는 §5 원칙). 선행조건을 넣는 재현은 **별도의 새
사전등록**으로 다뤄야 한다.
