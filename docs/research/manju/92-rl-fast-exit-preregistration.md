# RL 이 청산을 정한다 — 시장가 진입 · 강제 손절 없음 · 보유 10초 상한 — 사전등록 (92번)

## 0. 왜 재나

사용자(2026-09-16): "파바박 들어올 때는 시장가로 들어가야지", "10초 이상 버티지 마", **"그걸 고정값으로 정하지 말고 RL 로 정해."**

[90번 §5](90-big-wave-exit-exploration.md): 호랑이 신호에 시장가로 들어가 고정 익절/손절/시간으로 나오는 96조합이 전부 −38~−44bp.
−1호가 손절이 **88%** 발동했다 — 시장가 진입 직후 매수1호가가 이미 1호가 아래라 고정 손절은 구조적으로 불리하다.
92번은 손절·익절 문턱을 없애고 **RL 이 매 초 나갈지 정한다**. 보유 상한 10초는 사용자 지시로 고정한다.

[85번](85-rl-wave-riding-results.md)과 다른 점: 하드 손절 없음, 보유 10초 상한, 진입 후보를 **호랑이 신호 순간**(알고리즘 체결)으로 제한.
