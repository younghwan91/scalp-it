# 사전등록 — 짝꿍매매 (대장주 상한가 안착 → 후속주 5분)

**작성 시각:** 2026-08-23, **수익률을 한 번도 보지 않은 상태.**
**대상:** 만쥬 6대 기법 중 **짝꿍매매** — 테마 내 대장주가 상한가에 안착하는 순간 같은 테마
후속주(+10~15%)를 매수하고 1~5분 내 매도.

> 사용자 전언: 만쥬가 "요즘은 짝꿍이 대세" 라 했다. **기대가 클수록 설계를 더 엄격히 한다.**
> 12번 시험에서 채택 0개를 낸 뒤 쓰는 13번째 사전등록이다. 살려 보려고 규칙을 늘리지 않는다.
> 아래에 적은 것만 측정하고, 못 넘으면 기록하고 접는다.

## 0. 먼저 못 박는 것

- **수익률은 이 문서를 커밋한 뒤에 계산한다.** 지금까지 계산한 것은 이벤트 **건수**뿐이다
  (부록 A, `scripts/pair_events.py`). 진입 이후 가격은 어떤 형태로도 읽지 않았다 — 유일한
  예외는 진입 분(T+1) 시가가 상한가라 살 수 없는 건을 빼기 위해 그 한 봉의 **시가**를 본 것이다.
- **테마 데이터가 없다.** 레포·DB 어디에도 테마 소속이 없고, 키움 테마 API(ka90001/ka90002)
  는 **현재 스냅샷**만 주어 과거 소속을 복원할 수 없다 → 룩어헤드라 **사용 금지**.
  그래서 "같은 테마" 를 **대체 정의**로 쓴다(2절). 이 대체가 만쥬의 테마와 얼마나 닮았는지는
  알려진 짝 몇 개로 눈검사만 했다 — 정량 검증은 불가능하다.
- **"수급 증가세 둔화" 청산은 검증 불가**(틱·호가 없음). 시간 청산·손절·대장 이탈 청산만 가능하다.
- 표본은 분봉이 있는 **1년**(2025-08~2026-08), 종목은 **일봉 이벤트로 선별된 755 종목**뿐이다.
- 2절의 테마 정의는 **이벤트 건수를 보고 확정했다**(수익률이 아니다). 그 사실을 숨기지 않는다.

## 1. 묻는 것

> **대장주가 분봉상 처음 상한가에 잠긴 분의 다음 분 시가에, 같은 클러스터(60일 잔차 상관 상위
> 30)에서 그 순간 +10~15% 에 있는 후속주를 사서 5분 뒤(또는 대장 이탈 시) 팔면,
> 비용·슬리피지 차감 후 평균이 양(+)인가?**

이것만 묻는다. "어느 후속주가 더 좋은가" 는 2단계 피처 진단에서 **관찰만** 한다(채택 없음).

## 2. "같은 테마" 의 대체 정의

후보 넷을 검토했다.

| | 정의 | 룩어헤드 | 평가 |
|---|---|---|---|
| A | 키움 테마 API | **있음** (현재 소속) | 사용 금지 |
| B | `stocks.sector` KRX 업종 26종 | 경미 (현재 스냅샷) | 너무 굵다. 사전 조사에서 대장·후속 페어의 85% 가 업종 불일치. 기각 |
| **C** | **일봉 잔차수익률 상관 클러스터** | **없음** (직전 60일만) | **주 정의.** 신생 테마는 놓친다 |
| D | 테마 무시 — 그 순간 +10~15% 인 전 종목 | **없음** | **비교 1회용.** 가장 단순하지만 짝꿍이 아니다 |

### C 의 파라미터 — 지금 고정

```
창        트리거일 직전 60거래일 (t−60 ~ t−1), daily_bars_adjusted 종가 로그수익률
잔차      종목 수익률을 소속 시장지수(거래소 → KOSPI 001, 코스닥 → KOSDAQ 101, sector_index)에
          OLS 회귀한 잔차. 겹치는 날 ≥ 40 아니면 계산 불가 (신규상장 제외)
클러스터  후속주가 대장주의 잔차 상관 유니버스 내 상위 30위 이내 & 상관 > 0  (≈2,600 종목의 1%)
```

**절대 임계가 아니라 순위를 쓴 이유:** 대장주마다 잔차의 잡음 수준이 달라 절대 상관은 종목 간
비교가 안 된다. 0.4 같은 임계는 부록에 기술통계로만 병기한다. 30 은 "2,600 종목의 1%" 라는
자연 경계에 가까운 값으로 **결과를 보지 않고** 정했다. 10/50 은 돌리지 않는다.

**프록시가 깨지지 않았는지 눈검사** (`scripts/pair_events.py --sanity`, 일봉만 사용):

| 일자 | 대장 → 알려진 짝 | 잔차 상관 | 순위 | 대장의 상위 8 |
|---|---|---|---|---|
| 2025-10-14 | 로보티즈 → 로보스타 | 0.52 | **5** / 2,530 | 에스피지·하이젠알앤엠·씨메스로보틱스·유일로보틱스·로보스타·엔젤로보틱스·티로보틱스·레몬 |
| 2026-01-05 | 에코프로비엠 → 에코프로 | 0.81 | **2** / 2,528 | 에코프로에이치엔·에코프로·대주전자재료·SFA넥셀·피엔티·동화기업·에코프로머티·에코앤드림 |
| 2026-01-05 | 삼성전자 → SK하이닉스 | 0.13 | 334 | (지수 회귀가 둘을 흡수한다 — 낮게 나와야 정상) |

형성된 테마(로봇·2차전지)는 60일 상관이 정확히 잡는다. **그날 처음 생긴 테마는 못 잡는다** — 이건
C 의 구조적 한계이고, 짝꿍 이벤트의 어느 만큼이 신생 테마인지는 알 수 없다.

### 건수를 보고 확인한 것 (부록 A) — 수익률은 아니다

트리거 순간 +10~15% 에 있는 종목(테마 무시, 분봉 있음) 6,141쌍의 대장과의 잔차 상관
**순위 중앙값은 1,184위**, 상위 30 이내는 **5.2%** 다. 즉 대장이 잠기는 순간 같이 오르고 있는
종목의 95% 는 60일 상관으로는 대장과 무관하다. 그래도 C 필터를 통과하는 페어가 1년에 320쌍,
트리거당 1건으로 줄이면 **210건**이라 판정 가능한 크기다. 그래서 C 를 주 정의로 확정했다.
(중간 점검에서 2주치만 봤을 땐 2건이라 D 를 주 정의로 쓸 뻔했다 — 1년 전체를 세고 되돌렸다.
이 판단에 쓴 정보는 건수뿐이다.)

## 3. 대장주 트리거

```
상한가     전일 원주가 종가(daily_bars) × 1.3 을 호가단위로 내림 (scripts/limitup_timing.py 재사용)
트리거 분  T = 분봉 종가가 처음 상한가와 같아진 분   ← "잠긴 분"
유니버스   T 까지 누적 거래대금 ≥ 300억 (룩어헤드 없는 일 500억 하한(08번)의 근사)
시각       T ≤ 15:13 (T+6 시가 = 15:19 가 존재해야 5분 보유가 성립)
건수       한 (대장, 일자) 에 트리거 1회 — 첫 잠김만. 풀렸다 다시 잠겨도 재트리거 없음
```

**"처음 닿은 분" 이 아니라 "잠긴 분" 을 택한 이유:** 만쥬의 표현이 "상한가 **안착**" 이다.
4차 일봉 상따에서 +25% 도달분의 70% 가 상한가에 못 갔다 — 닿은 분을 트리거로 쓰면 "안착" 을
기다리는 만쥬의 규칙과 다른 것을 재게 된다. 잠긴 분은 봉이 끝나야 알 수 있으므로 진입은
**다음 분**이다(5절). 닿은 분 → 잠긴 분 간격은 피처(`lead_touch_to_lock`)로 남긴다.
(부록 A: 61% 는 처음 닿은 분에 바로 잠긴다.)

**점상(09:00 봉 시가=상한가)** 은 규칙상 포함이지만 누적 거래대금 300억 게이트에 전부 걸려
**실측 0건**이다(점상은 체결이 거의 없다). 따라서 분리 보고 항목에서 뺀다.

분봉이 수정주가인 종목-일(15:30 봉 종가 ≠ 일봉 원주가 종가, 0.2% 초과)은 상한가 판정이
흔들리므로 제외하고 건수를 보고한다(부록 A: 1,087 종목-일, 전체의 약 0.6%).

## 4. 후속주 선택

```
시점       트리거 분 T 의 후속주 종가 (T 에 봉이 없으면 직전 봉 종가)
등락률     +10% ≤ close_T / 전일 원주가 종가 − 1 ≤ +15%   ← 만쥬 공개 수치 그대로 (01번 3-2, 08번)
거래대금   T 까지 누적 ≥ 50억 (프로젝트 공통 하한)
클러스터   대장의 60일 잔차 상관 상위 30 & 상관 > 0 (2절)
체결 가능  T+1 봉이 존재하고 T+1 시가 < 후속주 상한가
순위       후보가 여럿이면 대장과의 잔차 상관 최고 1건
제외       대장주 자신. 분봉 없는 종목(측정 불가 — 부록 A.4 수집 목록)
```

**+10~15% 를 그대로 쓰는 이유:** 유일하게 텍스트로 확인된 숫자라 바꿀 자격이 없다.
상단 15% 가 있어 후속주가 이미 상한가 근처인 건은 자연히 빠진다.

**순위를 상관으로 하는 이유:** "가장 짝꿍다운 것" 이 이 기법의 정의다. 만쥬는 "상승률이 낮은
것" 을 고른다고도 하는데(08번), 이건 피처 `fol_ret` 의 방향 가설로 남긴다. 거래대금 순위는 D
비교용에서 쓴다.

**후속주가 상한가로 직행하는 경우 — 종가베팅의 교훈.** 등락률 상위를 고르는 모든 규칙에서
상한가 기여를 분리해야 한다(`archive/README.md` 실패 6). 세 층으로 다룬다.
① **진입 분(T+1) 시가가 상한가면 체결 불가로 제외**(위 규칙. 실측 0건 — 15% 상단 덕이다).
② T+1 봉이 없으면(VI 정지·무체결) 제외(실측 69건).
③ 진입 후 5분 안에 후속주가 상한가에 닿은 건은 **수익에 포함하되 분리 보고**한다 — 매도는
상한가에서도 체결되므로(매수 잔량이 받는다) 실행 가능성 문제는 없지만, 수익의 몇 % 가 거기서
나오는지 봐야 한다. 상한가 도달분을 제외해도 주 판정 조건을 넘어야 채택한다(7절).

## 5. 진입 · 청산 · 손절

```
진입       T+1 분 시가 (트리거 확인 직후 시장가)
청산(주)   min( T+6 분 시가 [5분 보유] , 대장 이탈 시 다음 분 시가 )
           대장 이탈 = T+1 ~ T+5 중 대장 봉 종가 < 상한가 인 첫 분 k → 후속주를 k+1 시가에 매도
비용       왕복 34bp + 슬리피지 왕복 30bp = 64bp 기본 / 34bp(슬리피지 0, 낙관) / 94bp(보수) 병기
```

**T+1 시가인 이유:** 트리거는 T 봉이 끝나야 확정된다. T 봉 종가에 산다고 가정하면 봉 안의
미래를 본 것이다. 다음 봉 시가가 "확인 즉시 시장가" 에 가장 가깝다.

**슬리피지 30bp 의 근거:** +10~15% 에서 움직이는 종목을 1분 안에 시장가로 사고판다. 호가단위
1~2틱(5천~2만 원대 종목에서 10원 = 5~20bp)을 편도로 먹는다고 보고 편도 15bp. 추정이다 → 94bp 병기.

**대장 이탈 청산을 주 규칙에 넣은 이유:** 만쥬의 청산 B("대장주가 상한가에 못 미치거나 급락하면
즉시 매도") 는 텍스트로 확인된 규칙이고, 대장 분봉만으로 기계적으로 정의되며(틱 불필요), 이것이
없으면 "짝꿍" 이 아니라 "후속주 5분 보유" 다. 이탈 발생 건과 미발생 건은 **분해 보고**한다.

**분할 매도는 하지 않는다.** 1분봉으로는 1~5분 내 3:3:4 분할을 재현할 수 없고, 분할은 평균적으로
"시간 청산의 가중 평균" 이라 전량 5분 청산이 보수적 근사다.

**손절을 주 규칙에 넣지 않은 이유:** 1분봉으로는 봉 안에서 −2% 와 +2% 중 무엇이 먼저 닿았는지
모르고, 5분 보유면 손절이 발동할 시간도 거의 없다. 아래 보조 비교 1회로만 본다.

### 보조 비교 — 각 1회, 채택 판정엔 쓰지 않는다

| 이름 | 규칙 | 목적 |
|---|---|---|
| `브래킷` | 진입 후 T+1~T+5 봉에서 고가 ≥ 진입가×1.02 면 +2%, 저가 ≤ ×0.98 면 −2%, 둘 다 닿은 봉은 **손절 우선**(보수적), 아니면 T+6 시가 | 만쥬 +2~3%/−1~−2% · 스승 +2/−2 의 교집합 |
| `테마무시` | 클러스터 조건을 빼고, 그 순간 +10~15% 전 종목 중 **누적 거래대금 최고 1건** | 테마 프록시가 무언가를 더하는지 |

다른 임계(+3/−1 등)·다른 순위·다른 k 는 돌리지 않는다.

## 6. 피처 — 트리거 시점까지의 정보만, 8개 고정

데이터를 본 뒤 추가·삭제하지 않는다. 방향 가설을 미리 적는다.

| # | 이름 | 정의 | 가설 (유리한 방향) |
|---|---|---|---|
| 1 | `lead_lock_min` | 대장 잠김 시각 (09:00 이후 경과 분) | 이를수록 (오전 테마가 강하다) |
| 2 | `lead_touch_to_lock` | 대장 처음 닿은 분 → 잠긴 분 간격 (0 = 첫 터치에 안착) | 짧을수록 |

| 5 | `fol_tv_ratio` | 후속 T 까지 누적 거래대금 / 직전 20일 일평균 거래대금 | 클수록 |

| 8 | `n_cluster_up` | T 시점, 대장 상관 상위 30 종목 중 등락률 ≥ +10% 인 종목 수 | 많을수록 (테마가 살아있다) |

## 7. 판정 절차 — 2단계

**1단계 (무조건 진입 — 채택 판정).** 주 규칙대로 전부 진입. 아래 **전부** 만족해야 채택
(= 전진 기록 착수. 실전 투입이 아니다).

1. **64bp** 차감 후 평균 > 0 **그리고** 중앙값 > 0
2. 거래를 시간순 **4폴드**(건수 균등, 약 50건씩)로 나눠 **음수 폴드 ≤ 1개** (64bp 기준).
   월별 13개도 보고하되 월 3~7건인 달이 있어 판정엔 쓰지 않는다
3. 상위 1% 제거 후에도 64bp 차감 평균 > 0
4. 진입 후 5분 내 후속주 상한가 도달 건 제외해도 64bp 차감 평균 > 0
5. 승률 > 50%

하나라도 못 넘으면 **기록하고 접는다.** 파라미터(등락률 구간, 보유 분, 거래대금 하한, 상관 창,
k=30)를 바꿔 재시도하지 않는다. `테마무시` 비교가 주 규칙보다 좋게 나와도 그것을 채택하지 않는다
(비교는 해석용이다).

**2단계 (피처 진단 — 채택 없음).** 1단계 결과와 무관하게 실행하되 **무엇도 채택하지 않는다.**
- 8개 피처 각각: 64bp 수익과 스피어만 상관, 5분위별 평균·중앙값·승률. 8개 전부 보고.
- 얕은 GBM(max_depth=2, n_estimators=100) 으로 "64bp 수익 > 0" 예측, **시간순 3폴드** AUC.
- AUC < 0.60 이면 "분봉으로는 선별 불가" 로 기록. ≥ 0.60 이어도 **후속 사전등록 대상으로만**
  기록한다(8차와 같은 이유 — 1년·210건에 8피처면 과적합이 기본값이다).

**보고할 것 (평균만 보지 않는다):** n, 트리거당 후보 수, 평균·중앙값, 승률, 손익비,
p5/p25/p75/p95, 4폴드·월별, 비용 3단계, 분해 4종(대장 이탈 발생 여부 / 후속 상한가 도달 여부 /
잠김 시각 구간 / `touch_to_lock`=0 여부), 같은 후속주 재등장 횟수(최대 5회 — 샌즈랩), 제외
사유별 건수. **그리고 실제 선택된 (날짜, 대장, 후속, 시각) 목록을 눈으로 본다** — 실패 6 의 교훈.
