# 아카이브 — v1·v2 시기 기록

여기 있는 문서는 **현재 방향(만쥬 일중 단타 복제)과 무관**하다. 지우지 않고 남긴
이유는 하나다 — **여기 적힌 실패가 같은 실수를 두 번 하는 것을 막는다.**

현재 상태는 [`../STATUS.md`](../STATUS.md) 를 보라.

## 무엇이 있었나

| 시기 | 목표 | 결말 |
|---|---|---|
| v1 | 2~8주 스윙, 이벤트 = 거래대금 급증 | 폐기 |
| v2 | 2~8주 스윙, 이벤트 = 공시 접수 | 폐기 |

두 버전 모두 **라벨이 40일씩 겹쳐 실효 독립 관측이 14개**뿐이었다.
그 표본으로는 무엇도 확정할 수 없었다.

## 반드시 기억할 실패 다섯

이것들이 이 폴더를 남기는 이유다. **단타에서도 같은 함정이 있다.**

**1. 전체 표본 평균 하나로 판정하면 안 된다**
`2026-08-17-baseline-verdict.md` — 전체 percentile 100 으로 PASS 였는데
폴드별로 뜯으니 3/4 폴드에서 전략과 랜덤 널이 소수점 넷째 자리까지 같았다.
전체 "엣지"는 폴드 하나가 만든 착시였다.

**2. 유니버스가 도중에 바뀌면 폴드 비교가 성립하지 않는다**
`2026-08-17-universe-shift.md` — `supply_demand` 커버리지가 2024년에
630 → 2,700 종목으로 뛴다. 대형주로 학습해 대형주+소형주를 검증하고 있었다.
분포 이동을 레짐 변화로 오독했다.

**3. 중복 매수를 막지 않으면 결과가 통째로 부풀려진다**
`2026-08-17-supply-layer-pass.md` 정정 — "전면 통과"로 보고했던 결과가
같은 종목 재매수를 금지하자 평균 +13.93% → +4.40%, **중앙값 +5.23% → −1.58%**.
폴드 3 의 72건 중 68건이 삼성전자·SK하이닉스였다. "동시 보유 20종목"이
실제로는 "같은 종목 20번"이었다.

**4. walk-forward 결과를 전역으로 풀링하면 안 된다**
폴드마다 예측값 스케일이 달라, 전역 분위로 나누면 "예측이 센 행"이 아니라
"스케일이 큰 폴드의 행"이 최상위에 모인다. 이 버그 하나로 절대 임계 성과가
−1.77% ↔ +5.05% 로 뒤집혔다.

**5. 사후 선택은 조용히 들어온다**
`2026-08-17-topn-preregistration.md` — `top_n=15` 인데 하루 후보가 중앙값 8건이라
선택이 아예 일어나지 않았다(`selection_ratio = 1.0`). "동시 보유 15종목"을
"날짜당 15종목"으로 구현한 것이 원인이다.

## 단타에서 같은 함정의 형태

| v1·v2 실패 | 단타에서의 대응물 |
|---|---|
| 전체 평균만 보기 | 연도별·분위별을 항상 함께 본다 (종가베팅 판정에 반영됨) |
| 유니버스 변화 | 거래대금 하한을 고정하고 분위별로 쪼개 본다 |
| 중복 매수 | 하루 상위 N 을 세되 **같은 종목 재진입**을 별도로 점검한다 |
| 전역 풀링 | 폴드 안에서만 분위·임계를 계산한다 |
| 사후 선택 | 사전등록 후 1회 측정. `manju/06-closebet-preregistration.md` 참고 |

**추가로 단타 고유의 함정 하나** — 상한가 오염.
`manju/04-closebet-daily-spike.md` 에서 등락률 상위를 고르니 수익의 전부가
상한가 마감 종목에서 나왔는데, 상한가는 종가에 매수 체결이 안 된다.
**등락률·급등 상위를 고르는 모든 규칙에서 상한가 기여를 분리 보고해야 한다.**
