# PEAD 실전 운영 런북

실적 서프라이즈 후 표류(Post-Earnings-Announcement Drift)를 롱숏 시장중립으로
굴리는 법. 이 프로젝트에서 **백테스트가 구조적으로 성립하고 강건성까지 통과한
유일한 전략**이다(`docs/research/manju/23`·`24`). 여기서 규칙을 바꾸면 그 순간
검증의 자격이 사라진다 — 파라미터는 확정본(`RULE_VERSION = v1-2026-08-23`) 그대로 쓴다.

## 0. 한 줄 요약

분기 실적 avail 이 뜨면 → 영업이익 YoY 서프라이즈(SUE)로 그 분기 유니버스에
데실을 매겨 → **롱 = Q10(최상), 숏 = Q1(최하)** 각 47±종목 동일가중으로 →
avail 익일 시가에 롱=숏 총액으로 진입 → +40거래일(≈2개월, 다음 분기 신호까지) 보유
후 청산. 시장중립. 백테스트 기대 **분기 net +4.47% (t=6.15)**, 엣지는 **숏 다리**.

## 1. 전략 스펙 (확정 — 바꾸지 말 것)

| 항목 | 값 |
|---|---|
| 유니버스 | 진입 직전 20거래일 평균 거래대금 ≥ **50억**(5000백만원), 스팩 제외, 진입일 상한가(체결불가) 제외 |
| 시그널 | 영업이익 YoY 서프라이즈 `SUE = (op_income − op_income_prior) / |op_income_prior|` |
| 포트폴리오 | 분기내 데실. **롱 = Q10, 숏 = Q1.** 각 동일가중 |
| 진입 | avail(실적 공시 반영 가능일) **익일 시가**(수정주가) |
| 보유 | **+40거래일**(분기 리밸). 다음 분기 신호가 오면 교체 |
| 비용 가정 | 롱숏 왕복 **68bp** + 숏 차입 ~50bp(2개월) |
| 자본배분 | 시장중립 — **롱 총액 = 숏 총액**. 각 다리 안에서 동일가중 |

배포는 50억 유니버스(47종목/side)를 쓴다. 500억 유동성서도 롱숏 net>0(t=2.54)이나
종목 7개/side 로 과집중 → 배포는 50억. 500억선 롱온리 초과수익은 무의(t=0.48)라
**롱온리 단독 운용은 비권장** — 엣지는 롱숏(특히 숏)에서 온다.

## 2. 분기 실행 체크리스트

분기 리밸이라 매일 돌 필요 없다. **새 분기 실적 avail 이 도착한 주에 한 번** 돈다.

1. [ ] 환경: `export $(grep -v '^#' ../kr-quant/.env | xargs)`, DB 컨테이너 확인
       (`docker start quant-airflow-timescaledb-1`).
2. [ ] **포트폴리오 생성**: `scalp-pead-portfolio` → 롱/숏 표 + `data/pead_portfolio_YYYYQ.csv`.
       새 분기가 형성됐는지(period 가 지난 분기와 다른지) 확인.
3. [ ] **리스크 오버레이 확인**: 롱 표의 `risk_flag`. **DART DB 는 2023 종료라
       최신을 못 준다** — 플래그 없음 = 안전 아님. 진입 당일 DART Open API 로
       각 롱 종목의 최근 공시(감자·유증·횡령·거래정지·실질심사)를 직접 확인(§5).
4. [ ] **전진 기록**: `scalp-pead-watch` → 확정 롱숏을 `data/pead_forward_log.jsonl`
       에 append(이미 기록된 분기면 조용히 건너뜀). 채점의 기준점이 된다.
5. [ ] **집행**: avail 익일 **시가**에 롱 매수 / 숏 대차매도. 롱 총액 = 숏 총액.
       한 종목 상한가로 시가 체결 불가면 그 종목만 스킵(유니버스 규칙과 동일).
6. [ ] **보유**: +40거래일. 중간 손절 없음(전략 규칙에 없다 — 넣으면 다른 전략).
7. [ ] **성과 점검**: 아무 때나 `scalp-pead-report` — 미실현/실현 손익을 기대치와 비교.
8. [ ] **청산**: 목표청산일(진입 +40거래일) 종가/시가에 전량 청산. 새 분기 신호가
       그 전에 오면 리밸로 교체.

## 3. 세 개의 CLI

| 명령 | 역할 | 쓰기 |
|---|---|---|
| `scalp-pead-portfolio` | 오늘 매매할 롱숏 표 + CSV. 비중·기준가·리스크 플래그 포함 | `data/pead_portfolio_YYYYQ.csv` |
| `scalp-pead-watch` | 확정 롱숏을 전진 기록에 append(append-only, 분기 멱등) | `data/pead_forward_log.jsonl` |
| `scalp-pead-report` | 전진 기록을 읽어 실현/미실현 손익 채점, 기대(+4.47%)와 비교 | (없음, 읽기전용) |

공통 옵션: `--asof YYYY-MM-DD`(기준일), `--dsn`(생략 시 `KR_QUANT_DB`).
`scalp-pead-portfolio` 는 `--dart-db`(공시 SQLite), `--out-dir`, `--no-save`.

## 4. 비용·손익 정의

- 손익: 롱 `(현재/청산가 − 진입가)/진입가`, 숏은 부호 반전.
- 롱숏 분기수익(spread) = 롱 평균 + 숏 평균(둘 다 '이익' 부호). 백테스트 net
  +4.47% 와 직접 비교되는 값.
- net = gross − (왕복 68bp 를 다리마다 절반 + 숏은 차입비 추가). `scalp-pead-report`
  가 gross/net 둘 다 낸다.

## 5. 리스크

- **숏이 엣지이자 리스크.** 소형주 숏은 숏스퀴즈·대차 회수·상한가 위험. 대차
  실행가능성은 2024+ Q1 종목의 `short_selling` 등장률 99%로 확인 → 대차 가능하나,
  개별 종목은 진입 전 대차 가능/수수료를 반드시 확인.
- **섹터·소형주 편중.** 데실 상·하단은 특정 테마(로봇·바이오 등)로 쏠릴 수 있다.
  포트폴리오 표의 시장·섹터로 편중을 눈으로 확인. 단일 섹터 과다면 캡 고려(단,
  캡을 넣는 순간 검증된 규칙에서 벗어남 — 별도 변형으로 기록).
- **악재 롱 회피(리스크 필터).** `scalp-pead-portfolio` 의 리스크 오버레이가
  감자·유증·횡령·거래정지·실질심사 등 명백한 악재 공시가 걸린 롱을 플래그한다.
  이건 수익 예측이 아니라(유형층은 수익 신호 없음) "명백한 악재 롱 회피"다.
  **한계: `data/dart_full.db` 는 2016~2023.** 최신 분기를 못 덮으므로 실운영 시
  진입 당일 DART Open API(`pead_risk.fetch_recent_disclosures` 훅 자리)를 조회해야
  한다. 플래그 걸린 롱은 진입 재검토(다음 종목으로 대체 또는 스킵).

## 6. 중단 기준 (kill switch)

전진 기록이 채점되기 시작하면 아래 중 하나라도 걸리면 **집행 중단하고 재검토**:

- 청산확정 분기의 롱숏 net 이 **연속 3분기 음수**, 또는 누적 net 이 백테스트
  기대의 절반(분기 +2.2%) 이하로 4분기 지속.
- 숏 다리 실현이 롱 다리를 구조적으로 못 이김(엣지 소멸 신호) — 백테스트는 엣지가
  숏에 있다고 했으므로 이게 무너지면 전제가 깨진 것.
- 대차 불가·수수료 급등으로 숏 다리 구성이 반복적으로 불가능.
- 규칙 파라미터를 손대야만 성과가 나오는 상황 — 그건 이 전략이 아니라 과최적화.

## 7. 근거

- `docs/research/manju/23`·`24`: 11년 롱숏 시장중립, 50억 유동성서 34bp+숏차입
  차감 후 **net +4.47%(t=6.15)**, 500억서도 net>0(t=2.54). 엣지는 숏 다리.
- 이 프로젝트는 백테스트를 믿었다가 두 번 틀렸다(분할 미조정·중복매수). 그래서
  `scalp-pead-watch` 전진 기록으로 **오늘부터 손 안 댄 창**을 만들어 채점한다.
  채택은 실전 성과의 증명이 아니라 전진 기록 착수를 뜻한다.
