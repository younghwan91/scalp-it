# autoresearch 사전등록 1 — 야간 보유 종목 선택 (결과 전, 2026-10-24)

## 무엇이 되면 끝인가
- **이 세션**: 평가기·기준선 train·program·이 문서를 결과 전에 커밋하고 태그 → quant-reviewer 심사 CRITICAL/MAJOR 반영(정정 문단 + 새 태그)
  → 기준선 1회를 원장에 기록 → 루프 에이전트가 Orca 터미널에서 돈다. 커밋은 브랜치까지만(push 없음).
- **이 루프**: 아래 졸업 바 b1~b7 을 **전부** 넘는 후보가 나오면 전진 모의매매(dry-run) 사전등록을 새로 쓴다. 바를 하나라도 못 넘으면
  기록하고 그 후보는 다시 심사하지 않는다. 잠금 3회를 다 쓰면 이 루프의 과거 데이터 심사는 끝난다.

## 왜, 무엇을
사용자 지시(2026-10-24): "이 레포도 autoresearch 를 시작해" — karpathy/autoresearch 루프에 dietmarwo/autoresearch-trading 의 분리(구조 = LLM,
숫자 = 폴드별 최적화기의 고원 선택)를 붙이고, swing-it 평가기 v1 리뷰의 C1~C4·M1~M8 을 처음부터 반영한다.

scalp-it 의 사전등록 전진 판정은 **10/10 기각**으로 프로그램이 종결됐다(`docs/TRADING_CRITERIA.md`, `scripts/forward_verdicts.py`).
그 10개는 전부 **일중**(수초~수십 분 보유) 정책이다. 같은 정의를 파라미터만 바꿔 다시 돌리면 낚시다. 그래서 대상을 그 판정들과
**다른 수익 다리**로 잡는다.

- **대상**: t 일 종가 단일가(15:30)에 사서 t+1 일 시가 단일가(09:00)에 판다. 매일 다시 고른다. 97번이 "수익은 전부 야간, 일중은 잃는
  구간"이라 했고, 108번이 야간 다리를 "비용과 같은 자릿수, 단일가 체결 비용 측정 없이는 못 정한다"로 **판정 없이** 남겼다.
- **질문**: 종목 **선택**이 정가 비용을 넘는 알파를 내는가. 시장이 밤에 오르는지(타이밍)는 묻지 않는다 — 점수에서 지운다.
- 루프의 산출물은 결론이 아니라 **전진 모의매매 팔 후보**다. 실주문은 이 문서 밖이다(PROMOTION_CHECKLIST·사용자 승인).

## 판정들과의 독립 — 그리고 이미 본 것(공개)
| 항목 | 기각된 10개 | 이 루프 |
|---|---|---|
| 보유 | 수초~수십 분, 일중 | 하룻밤(종가 → 다음 시가), 일중 노출 0 |
| 데이터 | 틱·호가 17~28일, 분봉 285일 | 일봉 `daily_bars_adj_v2` 2007-11-22~2026-09-30(상폐 포함 수정가) |
| 지표 | 거래당 평균 bp, 전진 7게이트 | 노출 맞춘 선택 알파(bp/일) 폴드 평균 − 0.5σ |
| 잠금 | 전진 날짜 | 종목 절반(솔트 sha256) + 개봉 3회 상한 + 전진 |

**이미 본 것**(이 데이터 위의 기술 측정, 판정 아님):
- 97번(일봉 `daily_bars` 2016-09-09~2026-09-16): 전일 거래대금 순위별 야간 총수익(상위 300 +26.3bp … 901+ +7.4bp), 전일 수익률 순위별
  일중, 전일 급등 상위 10% 의 야간 +80.5bp 중 55bp 가 상한가(종가에 못 삼), 개장 동시호가 스프레드 19.1/30.7bp.
- 108번(분봉 2025-08~2026-09): 시간대 분해 — 1~100 위 × 15:00→익일 09:00 +43.9bp, 시장별 비용 뒤 거래소 +5.7 / 코스닥 −6.4.
- swing-it 이 2008~2016 일봉을 스윙(수일~수개월) 구조에 썼다(다른 지평).
- 그래서 시험 폴드를 **시대 A = 2010~2016-08**(scalp-it 이 야간을 보지 않은 구간)와 **시대 B = 2016-09~2026-08**(97·108 이 본 구간)로
  나눠 보고하고, 졸업 바 b1 은 두 시대 모두 양수를 요구한다.
- **기준선 train.py 는 97번 표의 칸 그대로**다(전일 거래대금 순위). 이미 본 칸에서 출발한다는 뜻이다.
- **커밋 전에 본 것**(스모크, 2026-10-24 04:3x): 점수·알파·수익은 계산하지 않았다. 본 것: 탐색 절반 1,658종목 × 4,647일, 유니버스 하루 중앙
  375(2010)~750(2022)종목, 왕복 비용 중앙 62bp·90분위 105bp, 자료 이상 1,218칸, 출구 미룸 1,731칸, 출구 없음(−100%) 317칸,
  폴드 0·17 의 기준선 체결 수(2,510·1,620), 평가 소요(스모크 5초). 거래대금이 백만원 단위라는 것을 그 첫 빌드에서 발견해 고쳤다(유니버스 0 → 정상).

## 고정 절차(`prepare.py`, 태그 `autoresearch-overnight-prereg-1` 뒤로 바꾸면 평가 거부)
- **데이터**: `daily_bars_adj_v2`(상장 = 원주가 × 이벤트 누적계수, 폐지 = 네이버 수정가). 보통주(코드 끝 0)만, 스팩·코넥스·시장 미상 제외.
  `pre_listing`·`no_krx_source`·`minute_basis_mismatch` 행은 결측, `halted` 는 거래량 0. 거래일 = KOSPI 지수(`sector_index` 001) 날짜.
- **종목 절반 잠금**: sha256("scalp-it/autoresearch-overnight:" + 코드) 첫 바이트 짝 = 탐색, 홀 = 잠금. 디스크에는 탐색 절반만.
  잠금 절반은 `--final` 때 DB 에서 메모리로만 만든다.
- **유니버스(t−1 정보)**: 전일 거래, 전일까지 60일 중 55일 이상 거래, 전일까지 20일 평균 거래대금 ≥ 5억원, 전일 원주가 ≥ 1,000원.
- **신호가 보는 것(같은 봉 금지, M5)**: t 열 = t 일 시가 + t−1 일까지의 OHLCV·거래대금 + 지수 t 일 시가·t−1 일 종가 + 가격제한폭 + 시장 구분.
  t 일 고가·저가·종가·거래량은 없다. 날짜·종목코드도 없다(C3). 배열은 읽기 전용 복사본(M7).
- **체결(평가기만)**: 진입 = t 일 종가. 종가가 제한폭 0.5%p 안(상한가)이거나 t 일 정지면 못 산다(빈 슬롯은 현금).
  청산 = 다음 거래 가능일 시가. 정지일·하한가 잠김(시가 하한가 ∧ 고가 = 저가)에는 못 판다 → 다음 날로 미룸. 시가가 하한가인데 안 잠겼으면
  그날 **저가**에 판다(보수). 60 거래일 안에 출구가 없으면 −100%. 하룻밤 |시가/종가 − 1| > 제한폭 + 1%p 는 자료 이상으로 표본에서 뺀다
  (전략·벤치마크 모두). 슬롯 수 K ∈ {5, 10, 20, 40}, 한 종목 1/K.
- **비용(정가)**: 매도일 증권거래세·농특세(`krx_quant_core.costs.tax`, 매도일 세율) + 수수료 편도 0.015% × 2 + **단일가 슬리피지 편도 1틱**
  (2023-01-25 전후 호가표, 원주가 기준). 1주 단일가 주문은 체결가에 그대로 붙으므로 1틱은 보수 가정이다. 왕복 중앙 62bp.
- **점수(C4)**: 날마다 α_t = 포트 순수익_t − 노출_t × 벤치마크_t. 벤치마크 = 그날 체결 가능 유니버스 전 종목 동일가중 **총**수익(같은 체결 규칙).
  노출_t = 산 종목 수 / K. 폴드 값 = 시험 구간 날 평균 α(bp/일, 안 산 날 0). 점수 = 18 폴드 평균 − 0.5 × 표준편차.
  쉬는 날·노출 조절은 점수를 못 올린다(테스트: 사후에 시장이 오른 밤만 고른 오라클도 점수 ≤ 0).
- **워크포워드**: 학습 2년 → 시험. 시험 폴드 18 = A 2010·2011·2012·2013·2014·2015·2016(~08) · B 2016(09~)·2017~2025·2026(~08).
  학습 구간에서 라틴 하이퍼큐브 48점 → 정규화 공간 이웃 5점 **중앙값** 최대(고원) → 시험 한 번. 학습 점은 체결 < 연 200 이면 버린다.
- **void**: 체결 < (연 50 × 폴드 연수)인 폴드가 2개 초과, 또는 시험 체결 < 연 200, 또는 미래정보 검사 실패.
- **미래정보 검사(C2)**: 평가마다 절단 3곳(37·71·93%) × 파라미터 2개(첫·끝 폴드)에서 V[:, :cut+1] 로 **새 모듈**이 만든 cand·score 가
  전체 신호의 앞부분과 같아야 한다.
- **train.py 가드(C1)**: AST 허용 목록(numpy·pandas·math·functools·itertools·collections·dataclasses·typing), 파일·OS·동적 실행·
  getattr·더블 언더스코어·난수·연도 정수·종목코드/날짜 문자열 금지. params ≤ 6개, 수치 범위 폭 ≥ 큰 쪽 절댓값의 1/3(int ≥ 3), choice ≥ 2값.
  cfg 는 `slots` 하나(청산·손절·비중 규칙 없음, M2).
- **무결성(C1)**: 태그 뒤 `prepare.py`·이 문서·`program.md`·가드 테스트·`pyproject.toml`·`uv.lock`·`MANIFEST.json` 변경 또는 미커밋이면 거부.
  MANIFEST 의 sha256(그 파일들 + 설치된 krx-quant-core `costs/tax.py`·`stats/sharpe.py` + 캐시) 대조.
- **keep(M8)**: 평가기가 판정 — 직전 BEST 대비 Δscore ≥ +0.5bp/일 ∧ 폴드 ≥ 60%(11/18) 개선 ∧ top5 종목 제거 점수 악화 ≤ 0.5bp/일 → `beats_best`.
  run.log 에는 요약만, 폴드·시대별 값은 `~/.cache/scalp-it/autoresearch_private/` 에만.
- **원장(M1)**: `research/autoresearch/ledger/RUNS.jsonl`(git 밖) + `~/.cache/scalp-it/autoresearch_ledger/RUNS.jsonl` 에 덧붙이고, 읽을 때 긴 쪽.
  N = 고유 train sha 수. 잠금은 같은 이중 기록의 `LOCKBOX.jsonl`, 개봉 기록을 **열기 전에** 쓴다.

## 졸업 심사(`--final`, 메인 세션만 — `AR_FINAL=main-session`, 루프 셸은 `AR_LOOP=1` 이라 거부)
심사 시점: 사용자가 정하거나, 루프가 기준선 대비 score +5bp/일 이상인 후보를 낸 뒤 그 후보로 30 실험 동안 keep 이 없을 때.
**바(전부):**
1. b1 탐색 절반 score > 0 ∧ 시대 A·B 평균 α 모두 > 0 ∧ 거래당 순수익 > 0 ∧ 일 순수익 > 0(비용 1배).
2. b2 score > 순위 무작위 · 후보 솎기 무작위 · 파라미터 무작위 널(각 100회, 같은 폴드 파라미터·같은 후보 비율) 95 백분위 셋 모두.
3. b3 탐색 절반 상위 5 종목 제거 score > 0.
4. b4 잠금 절반(파라미터를 같은 절차로 다시 고름) void 아님 ∧ score > 0 ∧ 폴드 ≥ 11/18 양수 ∧ 거래당 순수익 > 0.
5. b5 일별 α 의 Deflated Sharpe 확률(N = 그 시점 고유 시행 수) ≥ 0.95.
6. b6 일 순수익을 [유니버스 동일가중 야간, KOSPI 야간, KOSDAQ 야간] 에 회귀한 절편의 Newey-West(lag 5) t > 2.
7. b7 비용 1.5배에서 score > 0 ∧ 거래당 순수익 > 0.
**판정**: 전부 → 전진 dry-run 팔 사전등록(규칙·장부·판정 바를 결과 전에). 실패 → `LOCKBOX.jsonl`·`docs/TRADING_CRITERIA.md` 에 기록,
그 후보와 파라미터 변형은 다시 심사하지 않는다.

## 보고·검증
졸업 심사 결과마다 quant-reviewer 1 + haiku-verifier 10~20(시험 구간 거래를 원 DB 로 재계산)을 띄우고, CRITICAL/MAJOR 반영 전에는 결론을
보고하지 않는다. 손익비·기대값(거래당 순 bp)으로 보고한다 — 승률이 아니다.

## 미리 밝히는 한계
- 현금 배당은 넣지 않았다(배당락 밤의 가격 하락만 반영 — 보수). 폐지 종목은 원주가가 없어 수정가로 틱·가격 하한을 근사한다.
- 2023-01-25 전 호가표는 시장별 옛 표로 근사, 유가증권 5만원 이상 구간 외 경계 차이는 검증하지 않았다.
- 출구가 미뤄진 보유는 그 기간 슬롯을 점유하지 않는 것으로 단순화했다(1,731칸, 드묾).
- 모든 체결은 주문 1주에서 유효하다. 단일가 대량 주문의 충격은 이 연구 밖이다.
- 종목 절반 잠금은 같은 날의 시장을 공유하므로 시간 홀드아웃이 아니다. 깨끗한 확인은 전진뿐이다.
- 공통 가드(허용 목록·고원·원장)는 swing-it 평가기와 겹친다. krx-quant-core 로 옮길지는 사용자 결정이다.
